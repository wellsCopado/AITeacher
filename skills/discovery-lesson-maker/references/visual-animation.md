# 写实画面与教学动画

## 写实样段先于整课

用户要求“真实的感觉”时，先做少量但完整的运行画面，再扩题目和配音。先交付一整课、最后再补材质的顺序，在高楼课中已经失败。

1. **从照片提取制作问题。** 选择能看整体比例和材料细部的真实参考，读来源并实际看图；官方结构文字或轮廓图不能代替材质照片。写明具体差异，例如“底宽偏窄、退台等间距、缺少金属百叶、玻璃没有环境反射”，而不只写“还不够写实”。参考不足的区域另记近似，不拿AI概念图当真实依据。
2. **在目标网页先做外观样段。** 使用最终相机、导出网格、材质和灯光，查看整体、近景及一个有尺度关系的观察位置。对静止建筑不以箭头运动冒充写实动画；对动物还要看支撑和关键动作。可以复用通用引擎，不能复用上一个主题的材质和场景配置后直接宣称通过。
3. **逐项定位“假在哪里”。** 按下表优先修第一个主因，保留相同视角的返工前后画面。原位置被建筑/地面遮住就改相机位置或观察方式，不能只加大远裁剪面或把遮挡全关掉。一个漂亮角度不能遮住其他常用角度的缺陷。
4. **样段成立后再扩课。** 轮廓不对，先换几何路线；材质平，查贴图/法线/反射是否在导出网页保留；环境假，修光照、地面、尺度和接触。做不到时记录具体缺口并继续修核心段，不用题目、检查数量或“概念模型”标签补偿。

| 可见缺陷 | 应检查与修复的制作环节 |
| --- | --- |
| 像细棍/积木/玩具 | 同参考比较最大宽度与高度、退台/曲面/连接节奏。建筑可用有来源的轮廓/CAD/GIS建立网格；数据近似须说明。动物查完整体积、附肢与背腹差异。不要用增加细分代替改轮廓。 |
| 玻璃、金属、塑料像同一种东西 | 区分材料层，建立分缝/边缘/接头的真实几何与合理PBR响应；反射要有与场景相符的内容。均匀金属色加几条线不够，烘焙的高光也不能固定粘在转动表面。 |
| 主角像漂在展示盘上 | 建立符合主题的地面、接触影、天空/水/背景与尺度参照；外观场景和抽象实验台分别呈现。环境不靠复制随机物件填满。 |
| 全景还行，放大立刻穿帮 | 查关键部位UV、粗糙度、材质分层、连接、轮廓分面与贴图重复；按实际最大教学缩放验。纹理若只是窗格/斑点节奏，不能据它数真实楼层或结构数量。 |
| 仰视贴进墙内、翻底黑屏、关注点丢失 | 用实际网格或空间数据检查相机位置与视线遮挡；保留当前关注点与距离，给放大、缩小和归位。地面位置不能只凭坐标猜。 |
| 看起来丰富但仍像地图积木 | 远景体块只可作环境近似；主角近景必须有正确形体、接缝与材料，光照/反射/空气透视一致。不能把“有周边楼体”作为照片级证明。 |
| 只有剖视和标尺，没有现实对象的感觉 | 默认先认识真实外观，再进入明确标识的结构/数学表示；内部概念不用暖色外壳或假透明强行充当真实外观。切回后恢复外观材质、环境与相机。 |

## 制造感与素模诊断

实物重建先看主形体、关键连接与负空间。机器人应能辨认外壳覆盖范围、关节的真实轴线/偏置、承力连接、运动间隙和接触界面；不是给每段圆柱套一个白壳。品牌外形和内部布局需要对应同一型号/配置，未知内部另作清楚标识的概念图，不暗藏进主角。

对整体与关键部位输出同机位的材质图和素模图，定位几何与照明各自的问题。素模失真不能靠HDRI、景深、反射或刮痕遮住；材质图则检查真实表面层次而非统一高光。生产方式见[真实对象重建](real-object-reconstruction.md)。建筑的开放地图挤出只提供部分体量，不能因此跳过幕墙曲率、转角、退台构造和附近场景细部。

## 参考、光照和尺度的边界

用户禁止第三方生成模型时，遵守限制。自主网格可以依据有许可的科学数据、地图轮廓和事实参考，也可使用允许的环境光/表面材质；如实说明来源、加工与近似，不能把开放地图挤出称现场扫描、把光照素材称当地实拍。若用户禁止范围更广，按其原话限制，不能偷换概念。

环境反射、直接光和可见天空需要方向、色温与明暗关系一致。现场反射探针、HDRI、程序天空、光追或烘焙均是可选路线；选实际工具支持且在网页中有效的方式，不把某个渲染器写成所有主题的必要条件。检查导出后纹理、颜色空间、法线、粗糙度和反射，不用Blender效果图证明Web效果。

空气透视不能形成硬地平线、贴图夹取拉成竖条、地面露边或不属于所在地的山地。真实天空素材仅作场景光照/背景时标明用途；它不证明主角形体正确。

尺度按有证据的范围和教学用途设置；不是所有对象都有能验证到5%的真值。人物、车、建筑、沙粒等参照要用一致单位。观察镜头可以为教学调整，但“人眼高度/真实速度/实测力值”有明确映射才使用这些词。

## 视觉结论怎样写

对本次运行样段记录参考、实际画面、具体差异、修改与仍存在的问题。质量结论可以是“仍为体块示意”“已改善材质与空间，写实待评”“用户退回”，不能只写passed和文件哈希。技术测试只支持运行。用户明确退回的视觉版本保持失败；后续版本重新比较与评价，不把上一版通过字段继承到新资产。

正侧背底与关键动作按教学用途覆盖，不机械凑固定视图数量。翻面时保留当前部位和缩放，提起/观察补光须明确。专业参数化建模可以合格，禁止的是粗糙占位体冒充写实主角；纯光滑零件也不必伪造磨损。

## 动作设计

先写真实参考、关键阶段、接触部位、时间尺度和需要放慢的原因，再制作。至少让一个与学习目标有关的部件发生有意义运动。生物保留支撑；机械符合自由度和关节约束；系统模拟要声明简化和参数适用范围。

快速运动可同时提供：

- 常速参考/爆发演示：若已放慢必须标明，不能冒充实测速度。
- 分解观察：可暂停、逐阶段/拖动时间，明确统一慢放还是阶段重定时。
- 机制说明：将弹性储能、锁扣、接触和回收对应到实际运动部件。

受击、沙尘、空化、火花、变形或破裂是艺术效果时说明。视觉冲击不等于力值；不得把论文某样本/钢靶测力硬套给当前模型。力学计算需要明确的质量、时间、接触、求解器、单位和验证；不具备时不显示伪测力仪。

## 短片与镜头

优先用同一场景和同一资产渲染，减少短片和交互网格身份不一致。镜头按问题组织：建立环境 → 关键动作近景 → 可理解的慢放/剖示 → 归回完整对象；具体镜头数和片长随主题，不强制片头与炫技转场。

外部生成视频是独立视觉材料。检查完整时序中的主角身份、部件数量、连接、接触、环境和物理连续性。不能用它的每一帧当测量/精确解剖证据，不保证多段生成片天然是同一个体。没有合格成片就记录短片未交付，不拿写好的提示词冒充视频。

常规目标为可播放MP4、横屏1080级、连续运动；若目标设备/源片需要其他规格，解释实际选择。用ffprobe读真实时长、分辨率、帧率和音轨，抽看开头/运动峰值/结尾，浏览器播放验证。把2fps截图编码成30fps文件不等于流畅三维动画；浏览器截图GIF只可作为交互验证，不能当正式短片。

按设备测量再定优化预算。纹理大小和三角数只用于性能规划，不能宣布照片级或平板60fps。实例/LOD优化后复查形体、独立骨骼、阴影和题目数量，避免只保留UI响应而场景不动。
