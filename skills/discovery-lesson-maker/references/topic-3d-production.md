# 按主题做主角：从一个词到一个真实的三维模型

家长（2026-11-06）：“一定要下次写其他课程的时候，能真实写好，不要老糊弄和不管主题，用素材硬套，要根据主题去生产 3D 和制作课程。”

这一页管的是“主角三维模型怎么来”。它在 [主题与素材](topic-assets.md) 的第 4 步（按主题做素材）里展开，对任何主题都一样：动物、机器、交通工具、建筑、桥、植物、地貌。前面几次失败都卡在同一个地方：

- 机器人课里出现了一只机械臂，火箭课里还是机械臂的图，蟋蟀课的画面还在海底。这是**没按主题做**，拿现成的东西硬套。
- 机械臂、主持人、动物用圆柱、方块、球在代码里拼，或者用一张俯视图压成浮雕。这是**没真的做**，糊弄出一个形状。

所以先写清“真实的它是什么样”（主角卡），再选一条能做出它的路线，最后按最低线检查。三步都有文件，`scripts/check_package.py` 查，App 导入也查。App 自己做的课不过这三步就不收。

## 第 1 步：主角卡 `research/subject.json`（动手建模前写）

```json
{
  "topic": "火箭发射",
  "instance": "长征二号F运载火箭",
  "kind": "vehicle",
  "why_this_one": "中国载人航天用它，公开资料和照片最全",
  "references": [
    { "file": "research/refs/cz2f-pad.jpg", "angle": "整体", "source": "https://…", "license": "CC BY 4.0" },
    { "file": "research/refs/cz2f-side.jpg", "angle": "侧面", "source": "https://…", "license": "CC BY 4.0" },
    { "file": "research/refs/cz2f-boosters.jpg", "angle": "近景", "source": "https://…", "license": "CC BY 4.0" }
  ],
  "dimensions": [
    { "what": "全长", "meters": 58.3, "source": "https://…", "main": true },
    { "what": "芯级直径", "meters": 3.35, "source": "https://…" }
  ],
  "features": [
    { "name": "4 个助推器", "node": "booster_*" },
    { "name": "整流罩", "node": "fairing" },
    { "name": "逃逸塔", "node": "tower_escape" },
    { "name": "芯一级", "node": "core_stage" }
  ],
  "route": { "hero": "modeled-from-reference", "why": "没找到可用的扫描件和 CAD；按公开尺寸和三张照片在 Blender 建模", "tools": ["Blender"] }
}
```

- `instance`：主题里**具体是哪一个**。不写泛称：“火箭”不行，写“长征二号F”；“蜜蜂”写“意大利蜂的工蜂”；“大桥”写“杨浦大桥”。家长给的就是具体的，照原词。拿不准时选资料和照片最全的那一个，在 `why_this_one` 说为什么。
- `kind`：`animal`、`plant`、`machine`、`vehicle`、`building`、`structure`、`landform`、`other`。它决定下面的最低面数，以及能走哪条路线。
- `references`：**至少 3 张真实照片，至少 2 个角度**（整体、侧面、俯视、近景……）。照片放进包里 `research/refs/`，写来源和许可。只用真实照片：渲染图、插画、卡通、玩具和模型的照片都不算。建模时对着它们做，验收时拿它们和截图比。
- `dimensions`：**至少 2 条真实尺寸**，单位米，带来源。最长的那条标 `"main": true`，模型按它核对大小。
- `features`：**至少 4 个辨识特征**，就是别人一眼认出“这就是它”的地方：火箭的助推器和逃逸塔，螳螂虾的捕肢和复眼，斜拉桥的主塔和扇形拉索。每个写 `node`：模型里对应的节点名，可以用 `*` 通配。建模时按这个名字给部件命名。课里讲的部件也在这里。
- `route`：下一步选的路线和理由。

## 第 2 步：按主题选生产路线

从上往下试，前一条拿不到才往下走。试过哪些来源、为什么不行，写进 `route.why`。

| `route.hero` | 是什么 | 适合 |
| --- | --- | --- |
| `scan` | 现成的实物扫描：博物馆、科研机构（Smithsonian 3D、NASA 3D Resources、自然博物馆）、Sketchfab 上许可为 CC0 / CC-BY 的扫描件 | 动物、化石、文物、岩石、植物、交通工具 |
| `cad` | 制造商、机构公开的 CAD / BIM / 工程模型 | 机器、机器人、交通工具、建筑、桥 |
| `photogrammetry` | 用至少 3 张不同角度的真实照片或一段绕拍视频做照片建模（Meshroom、RealityScan 等），再修整 | 手边能拍到的东西、找得到多角度照片的东西 |
| `licensed-model` | 有许可的写实成品模型。要逐个看预览图：低多边形（low poly）、卡通、风格化、Q 版的不要 | 各类，要钱的写进“需要家长决定” |
| `modeled-from-reference` | 照着真实照片和真实尺寸在 Blender 里建模（硬表面建模：倒角、细分、真实的接缝和结构） | 建筑、桥、机械、交通工具。**动物和人不走这条** |

不论走哪条：

- **不在代码里用几何体拼**主角、部件和环境（`new THREE.BoxGeometry / CylinderGeometry / SphereGeometry …`）。检查器会扫 `web/src`。只有界面标记（箭头、高亮圈、刻度）可以用，在那一行写注释 `adw-allow-geometry: 用途`。
- **不拿别的主题的模型改改**，不拿 App 自带场景、示例课、上一节课的模型。主题变了，主角从第 1 步重新来。
- **不用一张照片压成浮雕**，不用视频或转盘图代替可以转着看的模型。
- 动物要真三维、要能动：骨骼绑定，动作按真实视频；没有可靠动作资料时只做静止的真实姿态，不编动作。
- 材质用 PBR：颜色、法线、粗糙度（最好还有 AO）。只有颜色图时用 `scripts/pbr_from_color.py` 补。加使用痕迹：污渍、磨损、雨痕，见 [写实画面](photoreal-pipeline.md) 的假感毛病表。
- 环境也按主题：主角真实所在的地方，地面、岩石、水、植物用扫描贴图（Poly Haven、ambientCG）。
- 只用免费素材和本机工具。要花钱的，写进 `课程设计.md` 的“需要家长决定”，不自己付费，也不因为没钱就降成几何体。

所有路线都拿不到能过第 3 步的主角时，**停下来如实写缺口**，不用替身凑一节课。App 自己做课时，这节课会被退回，家长看得到原因。

## 第 3 步：主角的最低线（检查器和 App 都查）

数写在 `assets/hero-floor.json`，`scripts/hero_model.py` 和 App 导入用同一份。

| 查什么 | 最低线 | 为什么 |
| --- | --- | --- |
| 三角面数 | 动物 15000；机器、交通工具、建筑、构筑物 20000；植物、地貌 10000；其他 15000 | 面太少就是方块拼的样子 |
| 部件的面数 | 6 个以上部件时，只有几十个面的部件不超过一半 | 一堆方块、圆柱、球拼起来的，一查就出来 |
| 颜色贴图 | 有，而且最大的至少 1024 像素 | 只有纯色材质，看起来像塑料玩具 |
| 法线或粗糙度贴图 | 至少一种 | 表面没有细节就是假 |
| 真实尺寸 | 模型最长的边和 `main` 尺寸差不超过 20%（1 单位 = 1 米） | 尺寸不对，数学题和画面就对不上，也看不出大小 |
| 辨识特征 | 每个 `features[].node` 在模型里都找得到 | 讲到的部件，模型里真的有 |
| 来源 | 主角的 `origin` 不是 `procedural`、`drawn`；描述里没有 low poly、卡通、风格化 | 不糊弄 |
| 代码几何体 | `web/src` 里除了标记了 `adw-allow-geometry` 的行，没有几何体拼的画面 | 不在代码里拼 |

过了最低线**只说明不是糊弄出来的，不说明像**。像不像，看第 4 步。

## 第 4 步：对着照片看

做完主角先做画面对照图（[家庭档案](family-profile.md) 第 6 节）：主角卡里的真实照片和同角度的实时截图、预渲染图并排。按 `features` 一个一个比：每个辨识特征在模型上像不像、位置对不对、比例对不对。不像的写进 `visual_gate.self_review`，返工主角，不往下做课。家长在课程卡片最上面先看这张图，像才发布。

## 换个主题试一遍（自查）

| 主题 | instance | kind | 先试的路线 | 辨识特征举例 |
| --- | --- | --- | --- | --- |
| 蜜蜂 | 意大利蜂的工蜂 | animal | scan（自然博物馆、Sketchfab CC 扫描）→ photogrammetry | 两对翅、花粉筐、复眼、腹部条纹 |
| 机器人 | 一款真实的人形机器人型号 | machine | cad（厂家公开模型）→ licensed-model → modeled-from-reference | 头部传感器、肩肘腕关节、手指、脚掌 |
| 火山 | 一座具体的层状火山（如富士山） | landform | scan / 地形高程数据（DEM）生成地形 → modeled-from-reference | 火山口、山坡的层、熔岩流道、山脚 |
| 地铁 | 一款具体的地铁列车 | vehicle | cad → licensed-model → modeled-from-reference | 车头、车门、受电弓或第三轨受流器、转向架 |

每个主题都从第 1 步开始，没有哪个主题可以跳过。
