# 自然语音与旁白导演

“真人感”来自讲稿、声线、发音、停顿和表演，不来自MP3/WAV扩展名。来源是合成就标合成，不能写成真人录音。

## 选择声音

优先使用有明确授权的真人录音，或已获授权的成人旁白素材；需要自动生成时选择自然、克制、适龄的合成声音。先制作/选择一小段包含中文、英文词句、数字/单位与提问的试听样本，再定声线和节奏。使用真实可用服务和当前条款，不凭“高级”“神经”“真人级”标签判断听感。

不克隆未授权个人声音，不以孩子本人的声音、姓名、录音或学习记录训练/提示外部服务。不要求用夸张娃娃音、卡通主持或广告腔。相同课程的叙述者应稳定，中文和英文发音自然清楚；跨课的新鲜感不等于每课随机换一个声音。

## 先写能说出口的台词

看着实际镜头/操作写旁白：一句只承担一个观察或问题，少用书面转折、目录式列举和连续术语。需要孩子想、转动、操作时留出空白，不问完立刻自答。英文出现在对应对象和动作旁，必要时单独配发音，不把中英文长段机械交替。

科学词、人名、数字、单位和多音字单独校音。不要把字幕简单按字符平均分成等长块；应按实际音频起止时间对齐。不是通过统一降速、插很多省略号和感叹号来制造情绪。

建立片段级提示：`镜头/操作 → 台词 → 语言 → 发音要点 → 停顿/让孩子回应 → 对应字幕 → 音频文件`。这些是制作侧记录，不能擅自往App严格Schema添加未知字段。

## 配制、听检、同步

- 实际听开场、英文、数字/单位、问题、错误帮助与情绪安抚，不仅听一句“你好”。检查机械顿挫、错重音、假热情、重复模板、抢话和长静音。
- 处理明显噪声、削波、爆音和片段响度差；背景音乐不能压住发音或观察声音。
- 在真实目标播放器里验证开始、暂停、继续、静音、重播、切题与字幕同步。暂停后旧句不能串进新题，语音播放完不等于孩子完成任务。
- 没有试听/目标设备播放条件时明示未听检/未实测，不把ffprobe检测到音轨写成自然好听。

保留高质量源录音和实际交付音频，格式按宿主能力选择。记录 `human-recording` 或 `synthetic`、来源/授权、语言、稿件版本、对应镜头、文件校验和实测时长。不要把系统TTS自动称真人。

## 当前App的实际边界

**探索课包（本Skill的默认交付）**：旁白音频随包放在网页里（如 `web/public/audio/`，代码用 `./audio/…` 相对路径载入），App 原样托管，不另配音。macOS `say` 或其他合成声音都标 `synthetic`；只在家里自用时可以先用，要给别人用或商用前，换成条款允许随课分发的声音或有授权的真人录音，并在 `licenses/` 写明。在家里的平板上实际听一遍，不只在电脑上听。

**LessonSpec 参数课**：App 的 `apps/server/src/tts.ts` 用 Mac `say` 生成 WAV，`packages/player/src/voice.ts` 优先请求服务器音频，失败回退设备语音。这是合成语音，代码中的声线排名不是已试听的质量证明。LessonSpec没有通用预录旁白片段字段；要使用预制自然音频需要确认宿主已有可用入口，否则在接入差距中提出，不擅自加字段或修改App。
