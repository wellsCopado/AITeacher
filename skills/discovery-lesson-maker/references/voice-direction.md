# 自然语音与旁白导演

“真人感”来自讲稿、声线、发音、停顿和表演，不来自MP3/WAV扩展名。来源是合成就标合成，不能写成真人录音。

## 选择声音

家长要的是“标准播音 / 像真人”，不是“能出声”。按听感从好到差选，能用前一档就不用后一档：

1. **有授权的真人录音**（家长或请来的播音员）：最自然，但每课都要录，只在重点课或固定用语上用。
2. **云端神经语音（默认）**：微软 Azure 神经语音（中文 晓晓 `zh-CN-XiaoxiaoNeural` 讲解、云扬 `zh-CN-YunyangNeural` 新闻播音；英文 Ava `en-US-AvaNeural`、Andrew `en-US-AndrewNeural`），每月 50 万字免费，一个密钥覆盖中英；火山引擎 豆包语音（中文最自然，按量付费）；OpenAI 兼容 `/audio/speech`（中文略带口音，只在前两个不可用时用）。
3. **Mac 的“高级 / 增强”声音**（Lilian 高级、婷婷 增强、Ava 高级）：免费、离线，但长句明显机械，只作云端不通时的兜底。
4. **Mac 普通声音或平板自带声音**：只作最后兜底，不能作为交付声音。

密钥只放在家里服务器（家长端「设备与数据 → 朗读声音 → 声音来源」）或做课时的环境变量 `ADW_TTS_KEY`，不写进课程包、代码、制作记录。

声线规则：同一课一个中文旁白、一个英文旁白，跨课保持稳定；中文选温暖清楚的成人讲解声线，英文选母语标准口音（美式为主），不用娃娃音、卡通腔、广告腔。Azure 风格（`style`）只用 `gentle`、`newscast` 或不设，不用 `cheerful`、`excited` 之类会显得假热情的风格。先做一小段试听样本（含中文、英文词句、数字/单位、提问），听过再定声线。不凭“高级”“神经”“真人级”标签判断听感。

不克隆未授权个人声音，不以孩子本人的声音、姓名、录音或学习记录训练/提示外部服务。

## “AI 味”从哪来、怎么去掉

| 听到的毛病 | 原因 | 规则 |
|---|---|---|
| 中英混读一句时断断续续、每段音调重新起 | 一句话被拆成多段分别合成再拼 | 整句一次合成：服务器 `/v1/tts?whole=1`，Azure 在同一段 SSML 里切换中英声线；其他引擎按语言分段后无缝拼接 |
| 假热情、忽高忽低 | 稿子里“！！！”“~”、表情、连续感叹 | 每句最多一个感叹号；不写 ~、表情、装饰符号（服务器和 `make_family_audio.py` 会自动清掉，但稿子本身就不该有） |
| 一字一顿、念目录 | 书面长句、括号、顿号连串 | 一句只讲一件事，15–25 个汉字；不用括号、斜杠、表格式列举 |
| 数字和单位读错 | “3.5m”“1/4”“2:1”等写法 | 写成要读的样子：“3.5 米”“四分之一”“二比一”；多音字、专有名词单独试听 |
| 语速被硬改后发僵 | 统一调慢或调快 | 用声线自己的语速，不统一改 rate；需要停顿就断句，不堆省略号 |
| 句尾总是上扬、像在念台词 | 每句都用问句或感叹 | 陈述为主，真提问才用问号；问完留出孩子思考的时间，不立刻自答 |

## 先写能说出口的台词

看着实际镜头/操作写旁白：一句只承担一个观察或问题，少用书面转折、目录式列举和连续术语。需要孩子想、转动、操作时留出空白，不问完立刻自答。英文出现在对应对象和动作旁，必要时单独配发音，不把中英文长段机械交替。

科学词、人名、数字、单位和多音字单独校音。不要把字幕简单按字符平均分成等长块；应按实际音频起止时间对齐。不是通过统一降速、插很多省略号和感叹号来制造情绪。

建立片段级提示：`镜头/操作 → 台词 → 语言 → 发音要点 → 停顿/让孩子回应 → 对应字幕 → 音频文件`。这些是制作侧记录，不能擅自往App严格Schema添加未知字段。

## 配制、听检、同步

- 实际听开场、英文、数字/单位、问题、错误帮助与情绪安抚，不仅听一句“你好”。检查机械顿挫、错重音、假热情、重复模板、抢话和长静音。
- **听检验收（交课前必须做，结果写进制作记录 `reviews.voice`）**：至少听 8 句，覆盖 开场 1、带数字/单位 2、中英混读 1、英文 2、答错后的鼓励 1、演示 1。每句判“自然 / 能接受 / 有 AI 味”；有一句“有 AI 味”就改稿或换声线重录，不能交。写明用的引擎和声线、听了哪几句、在什么设备上听的。
- 处理明显噪声、削波、爆音和片段响度差；背景音乐不能压住发音或观察声音。
- 在真实目标播放器里验证开始、暂停、继续、静音、重播、切题与字幕同步。暂停后旧句不能串进新题，语音播放完不等于孩子完成任务。
- 没有试听/目标设备播放条件时明示未听检/未实测，不把ffprobe检测到音轨写成自然好听。

保留高质量源录音和实际交付音频，格式按宿主能力选择。记录 `human-recording` 或 `synthetic`、来源/授权、语言、稿件版本、对应镜头、文件校验和实测时长。不要把系统TTS自动称真人。

## 当前App的实际边界

**探索课包（本Skill的默认交付）**：旁白音频随包放在网页里（`web/public/audio/family/`），App 原样托管，不另配音。用 `scripts/make_family_audio.py <web/public> --engine azure`（环境变量 `ADW_TTS_KEY`、`ADW_TTS_REGION`）配音；没有云端密钥才退到 `--engine mac`，并在制作记录里写明“用的是 Mac 声音，听感偏机械”。脚本同时写 `audio/family/voice.json`（来源 `synthetic`、引擎、声线）。换声线后用 `--redo` 全部重录，同一课不能混用两种声线。云端合成的声音给家里自用可以；要给别人用或商用前，确认服务条款允许随课分发，并在 `licenses/` 写明。在家里的平板上实际听一遍，不只在电脑上听。

**LessonSpec 参数课**：家里服务器现场合成。家长在「设备与数据 → 朗读声音」选声音来源：接了云端语音（`apps/server/src/voice-cloud.ts`）就用云端神经语音，云端不通时这一句自动改用 Mac `say`（`apps/server/src/tts.ts`），家长端会显示出错原因；平板按整句请求（`whole=1`），服务器不可用时才回退平板自带语音。这些都是合成语音，代码中的声线排名不是已试听的质量证明。LessonSpec没有通用预录旁白片段字段；要使用预制自然音频需要确认宿主已有可用入口，否则在接入差距中提出，不擅自加字段或修改App。
