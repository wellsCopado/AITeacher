# 从真实对象到有制造结构的网格

适用于用户要求现实实体的真实感，尤其是已经指出“积木、假、像玩具”的情况。这是制作路线，不是往提示词里加“8K”。原App、用户禁用的生成服务和既有授权范围继续保持。

## 先明确实际在重建什么

给一般主题选一个有充分资料、符合语境的真实代表；用户指定物种/型号/建筑时沿用，不替换成自创的类似角色。记录实际名称、配置与选型理由；外观图、尺寸图、结构说明和运动参考分别支持什么。无须把资料全找齐才开工，但决定主形体和关键连接的信息不能凭空补。

例如，完整人形只是类别。重建G1时还需对应具体手部配置和关节布局：[厂商产品资料](https://www.unitree.com/g1/)与[官方机器人描述](https://github.com/unitreerobotics/unitree_ros/blob/master/robots/g1_description/README.md)区分变体。URDF可支持轴线、父子关系和参考位置；不能据它臆造外壳曲面、控制板或每条线束。参考图片中的附件也不能不经核实并入另一个版本。厂商营销渲染、尺寸图与实拍/现场视频分别标明；营销图可说明设计，不能直接充当真实表面和运动的证据。

对主角挑少量真正影响视觉的依据：宽高关系、头/躯干/肢体体量、轴线偏置、转角或连接方式、典型负空间。已确认尺寸用一致单位，照片推估写近似，未知结构保留未知。照片透视与模型机位不同，不能硬算一个伪精确误差百分比。

scope的identity可补充：

```json
{
  "representation": "reference-reconstruction",
  "realObject": {
    "name": "本次实际选择的种类、型号或建筑",
    "basis": "为什么选它，与用户语境和来源如何对应",
    "sourceIds": ["实际来源id"],
    "anchors": [{"feature": "关键比例/连接/配置", "basis": "读到/看到的具体依据及近似", "sourceIds": ["实际来源id"]}]
  }
}
```

这是制作信息，不导入宿主课程Schema。以下命令能拦住缺少依据的自创角色，不能识别一个改名的错误网格；draft仍检查真实来源，但允许审查未完成。

```sh
python3 scripts/check_subject.py '/制作目录' --expected-subject '本次主角名称' --require-real-instance --draft
```

## 按真实构造建模，而非拼装外观符号

| 层次 | 实际制作 | 不足时先改什么 |
| --- | --- | --- |
| 主体量与曲面 | 从参考轮廓/尺寸确定截面、曲率变化与过渡；对称只用于真实对称部分 | 人形比例、胸肩连接、髋部轴系、动物背腹、建筑基部与顶部等关键体量，先于螺钉和划痕 |
| 部件连接 | 按轴线和父子关系布置安装座、承力路径、外壳覆盖、运动间隙与接触面 | 穿插、悬空、无安装位置、关节轴心与实际转动不符，不能靠暗光掩盖 |
| 次级结构 | 有依据地建立壳体边界、凹槽、台阶、支架、安装孔与法兰；需要近看/拆解的孔用真实几何 | 不把黑点当孔、不把粗圆柱当所有电机、不把薄贴片当可拆外壳；倒角按物体尺度设置 |
| 表面 | 把涂层、玻璃、金属、橡胶等材质分开，检查真实反射、粗糙度与法线 | 材料统一塑料化、法线导致端盖融化、UV密度错；新设备不强加脏污来显“真” |
| 场景与镜头 | 地面、影子、空气透视、反射和尺度参照共同成立 | 环境光不能替错误主体比例兜底；背景体块可以近似，主角与教学近景不能按远景质量制作 |

具体方法按对象选择：真实回转零件可从有尺寸依据的轴向剖面旋转成形；工业外壳可用截面放样、连续曲面、实体厚度和真实开孔；生物需处理组织轮廓、附肢连接与表面方向；建筑的GIS轮廓只是体量依据，还需幕墙、转角、退台及表面构造。不要把一种工具或一个预制体扩成所有主题的生产捷径。

尺寸和内部细节不明时，不伪装成精密装配。若教学需要一般机制，另做清楚标识的机制视图，保持外观真实对象的身份。禁止把别的厂商零件装进去后声称复原当前型号。

## 可运行的制作辅助工具

先核实本机Blender可执行文件；以下在Skill目录运行，将`blender`替换为实际命令。脚本不联网、不调用第三方生成模型，不保存覆盖输入资产。

```sh
blender -b --python-exit-code 1 --python scripts/render_asset_diagnostics.py -- --input '/制作目录/models/主角.glb' --out '/制作目录/diagnostics/整体' --views front,three-quarter --modes material,clay
blender -b --python-exit-code 1 --python scripts/render_asset_diagnostics.py -- --input '/制作目录/models/主角.glb' --focus '实际部件节点名' --out '/制作目录/diagnostics/部件' --views three-quarter --modes material,clay
```

输出同机位PNG、包围盒、输入/输出校验与机位数据。GLB导入会转换到Blender Z-up；直接诊断Y-up的Blend须加`--up y`。默认正交镜头利于看比例，不能用它证明最终网页透视。可选本地`--environment`，但不能因此把诊断照明当真实现场。缺失贴图、找不到部件会失败，不静默换白模。

回转零件的局部制作样例：

```sh
blender -b --python-exit-code 1 --python scripts/build_revolved_assembly.py -- --spec examples/revolved-actuator.spec.json --out '/制作目录/detail-sample'
```

生成真实回转网格、实体安装孔、独立分件、GLB和可编辑Blend。示例参考[CubeMars执行器尺寸资料](https://www.cubemars.com/product/ak80-9-v3-0-robotic-actuator.html)，把确认尺寸与外观推估分开。它是制作工具回归，不是完整人形机器人，不是G1内部，也不提供加工/装配或性能验证。新对象要从其实际资料重写剖面，不能照搬这个样例。

## 回到真实课程验证

同时看材质与素模：素模仍像玩具就先改几何和连接；素模成立而材质图失真再查表面与灯光。改变材质、灯光或焦距不应成为隐去错误的手段。

诊断之后仍须在最终Web检查近看、旋转、关节极值、遮挡和接触。模型/材质/缩放或LOD改变后，旧画面证据不自动沿用。开孔、关节、手指与外壳要保持真实节点，不能为了降面把数量或机构融合。

最后由主角的真实配置决定题目、数字、语音与观察问题：三指对象按三指设计任务，五指变体需有证据；不能为了延续旧题改动物种或设备结构。语文表达、英文和数学都服务孩子实际看到的现象，技术试课和孩子掌握仍分开。
