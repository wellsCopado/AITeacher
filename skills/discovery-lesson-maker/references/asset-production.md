# 从命题到合格写实三维资产

这里是制作方法，不是“多写几条写实要求”。原海景和旧App的程序拼物体、单图浮雕都不能作为合格基准。合格与否最终看真实资产在目标视角、动作和交互中的表现。

## 从零制课的资产检查

用户检验跨主题生产能力时，先固定本次不复用的历史视觉素材范围，记录新主角、参考、环境和成片来源。通用依赖和控制器不属于成品视觉素材；新检索的专业资产可以用，但如实记录检索、许可和修整，不说成自己从零雕刻。

图生3D后先验模型，再绑定和扩课。全角度检查灰白未烘焙区域、附肢融合、背景带入和身体扁平；底面未见于参考不等于可随意补成确定结构。自动名称与目标物种冲突时检查形态，不通过改名解决。失败时分别定位参考图、重建、纹理、材质或运动问题：贴图本身大片空白应重新烘焙/重建，不能靠补光掩盖。换模型版本属于新路线，保留参数与同角度对照；连续同样失败就停止同法消耗额度。

## 先选真实对象，不从造型方便开始

对于本用户的真实机器人，完整头/身体/手脚只是身份下限。还需具体实物的外观、比例、关节轴系与配置依据；用自创白色壳体、圆柱电机和五指手不能自然获得真实身份。先读[真实对象重建](real-object-reconstruction.md)，由证据决定几何和教学数量，再建模。

## 1. 由教学用途反推资产结构

先确定孩子需要看见/操作什么，再选资产：

| 用途 | 需要什么 | 不能替代它的东西 |
| --- | --- | --- |
| 整体观察与翻面 | 完整立体形体、可靠隐藏面、合适材质 | 俯视贴图挤厚、相片卡片、视频转盘 |
| 动物/人的动作 | 有关节逻辑的骨骼与权重，支撑和接触可检查 | 整体位移、软体橡胶拉伸掩饰错误附肢 |
| 机械原理和拆装 | 正确部件划分、支点/轴心、连接关系和运动约束 | 单一融合网格随意切碎后叫工程装配 |
| 内部构造 | 有来源的内部数据或明确标识的概念模型 | 对外壳加透明、凭空长出器官并称精确解剖 |
| 定量实验 | 参数与真实几何/状态/求解对应，有单位与参照算例 | 读数变化而物体不变、动画效果反推物理量 |

主体外形与连接先正确，再考虑4K和高面数。将材料暂时统一成哑光素模：如果仍是悬空相接的盒子、圆柱和同宽胶囊，就先修体积、曲面和连接，不先贴皮或加螺钉。单个模型不支持全部教学用途时，分别制作整体、机构近景和概念剖示，并说明各自依据；不得暗中用不同对象混过。

## 2. 自主建立可用于制作的参考

检索主角的真实照片、运动视频、权威结构资料和环境。挑能回答具体制作问题的视角：轮廓、接头、底部、材料、运动支点；不是为了达到固定照片数量而凑图。

制作者自行整理一张简短参考板：

- 身份与不可错特征，例如具体物种/型号、辨识部件、结构连接；
- 正侧背底和关键部位参考，对缺失区域标不确定；
- 尺度区间、材质组成、栖息/工作条件；
- 动作关键帧、支撑点、接触对象和真实时间尺度；
- 每条参考的来源/许可，以及将用于哪个部件或镜头。

AI概念图可以帮构图，不能反过来充当结构真值。不会从资料中确定的连接，不用漂亮纹理遮住后拿来出题。

## 3. 选择路线并先做一次资产试装

优先级由用途、质量、许可和修整成本共同决定：已有合格专业资产/扫描 → 可用CAD/科学数据 → 基于参考生成并修整 → 专业建模。没有任何路线保证一次成功。

选已有模型时先实际打开，核查完整形体、部件、动画和贴图，而不是看到缩略图就下载所有内容。生成时把身份、结构、材料与视角条件写清；只有在工具支持多视图/约束时才使用对应输入，不能假定所有图生3D服务都能多图重建。

生成/建模任务说明应具体到：

> 对象身份与已核实形态；整体比例与关键连接；需要单独运动/拆装的部件；表面材料；必须完整的底面；真实尺度范围；输出网格/部件/纹理/骨骼要求；哪些细节仍未知。环境参考和表演动作另列，不把一整套电影场景塞进主角生成提示词。

避免只写“超写实、8K、电影级、杰作”。提示词不是验收结果。先检查一个主角能否支持目标动作，再批量制作环境和变体。

## 4. 修整成能用的三维对象

根据缺陷使用实际可用的三维工具修整，不盲目重复生成：

- 结构：去除多余/融合部件，修补破面和不可见侧；重要形态错误严重时换路线，不继续给错误模型绑骨骼。
- 部件：按实际功能分节点，设置正确轴心、父子关系和限位，给交互部位稳定ID。拆解后要能归位。
- 表面：清理烘焙的假阴影、贴图拉伸与错位；让粗糙度、金属度、透明等对应实际材料。不是所有表面都需强行加磨损或法线。
- 动作：支点正确、权重不过度牵扯甲壳/硬件；接地、抓取与命中位置在真实画面里吻合。运动参考不足的近似明确标识。
- 空间：统一尺度/朝向/原点，地形采样对应实际三角面；翻面观察绕身体/物体中心，不能翻进地里。
- 运行：绑定、动画和控制实际导出或保留可编辑运行源码；原静态GLB与运行时加骨骼不能混称为已导出的动画模型。

宿主要求所有复杂体从文件加载时，可离线专业建模后导出合格文件。不要为通过代码白名单将粗糙占位物导出GLB后再导入，文件格式不会改变质量。

程序材质和建模软件里的效果不一定能导出到Web。把用到的微表面、粗糙度和颜色处理烘焙为受支持贴图，或转换为等效的导出材质，并在实际加载的GLB上检查UV、法线、颜色空间和光照。不能拿建模软件截图证明网页中的材质已保留。

在扩课前，按[写实样段](visual-animation.md#写实样段先于整课)完成实际Web比较。研究文字回答“是什么”，照片回答“看起来怎样”，二者不能互相替代。若只有示意轮廓与均匀材质，先保留为草模并继续制作，不急于生成整课。

## 5. 组装环境并导演动作

环境应为主角提供可信尺度、照明和接触，不靠堆满复制岩石/鱼/物件显得丰富。前景教学对象清晰，背景有层次；反射与光照符合环境。主角底部观察要补光或采用明确的观察灯，不能黑成一团。

每个关键动作列出“准备—发生—结果—回收”，但时间曲线与现象一致，不强制所有动作同样缓入缓出。快速打击、缓慢变形、机械限位的处理不同。慢放、阶段重定时、概念剖示都在相应位置说明，不能用不存在的精确倍速/物理值装饰。

## 6. 质量返工要改对象，不能只改措辞

用实际课程相机与灯光查看正侧背底、动作峰值和接触。发现问题后记录“哪一部位/哪一帧/为什么不合格 → 改什么 → 同角度重看”。轮廓错误优先于材质；关节错误优先于多加粒子；关键交互不可用优先于拍片。

相同路线连续失败且没有新证据就换诊断/路线，不重复同一提示词烧额度。资产尚不合格时标为制作中，不能因检查器0错误宣布写实达标。优化LOD/压缩后重新查看关键形体和独立动作，不能以性能为理由退回玩具主角。
