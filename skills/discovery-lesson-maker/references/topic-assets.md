# 写什么主题，就做什么画面：每个主题都走的五步

家长（2026-11-05）：“写啥主题就做啥图片啊，不要总是复用原来的素材”“把 skill 写好，步骤定好，约束写好，不是我说了你就改，下次我换个话题，又错了”。

起因：给妹妹写「火箭发射」，课里的字改成了火箭，图片还是机器人工厂的机械臂。前一天的蟋蟀课也一样，演示还是海底。这两次不是哪个主题特殊，而是做课的流程里没有一步要求“画面为这个主题做”，验收也查不出“只改了字”。

下面五步对任何主题都一样。每一步有自己的产出，下一步只从上一步的产出出发。没有为某个主题单独写的规则。

## 第 1 步：定主题和主角

- **主题**就是家长写的原词（「火箭发射」），写进 `exploration.json` 的 `topic`，一个字不改。
- **主角**是主题里那个真实的东西。写清具体是哪一个，例如长征二号F火箭、意大利蜜蜂的工蜂、富士山这样的层状火山。再写它真实所在的地方：发射场，蜂箱和花丛，火山口和山坡。
- 主题和主角都不能换：
  - 不换成孩子以前的兴趣，也不换成上一节课的主角。
  - 不换成更好做的东西。
  - 不换成 App 里已经有的场景：机器人工厂的机械臂、珊瑚礁、花园、积木。

**产出**：`课程设计.md` 开头的「主题与主角」，写主题原词、具体主角、它在哪里，以及拿不准的地方。

## 第 2 步：定这节课学什么

- 查主题的真实资料：机构、博物馆、论文、百科的原始来源。记进 `research/sources.json`，见 [研究和素材](evidence-assets.md)。
- 对照孩子的年级、课内进度和最近上过的课，从这个主题里真实存在的数学和科学里挑。比如蜜蜂有巢房的六边形和采蜜的趟数；火箭有倒计时、助推器个数，以及火箭和楼一比有多高。
- 定 1 个主问题、2–4 个学习目标。主导任务和最近的课不一样，不默认周长和面积。

**产出**：`课程设计.md` 的「学什么」，包括调研结果、学习目标和你的取舍。

## 第 3 步：动手之前，先列素材清单

把孩子会看到的每一样东西列进 `research/assets.json`：主角、部件、环境、题目和讲解的配图、视频。

清单里只能有三类东西：

1. 主角本身；
2. 主角的真实部件；
3. 主角真实所在的地方，以及那里真有的东西。

不能有：

- 别的主题的东西，例如火箭课里的机械臂、齿轮、积木、珊瑚；
- 卡通替身；
- 为了好做换上的东西。

```json
{
  "topic": "火箭发射",
  "items": [
    { "file": "web/dist/models/long-march-2f.glb", "sha256": "…", "role": "hero",
      "depicts": "长征二号F运载火箭（整箭，含 4 个助推器）", "made_for": "火箭发射",
      "origin": "modeled", "how": "Blender 按公开尺寸建模，脚本 tools/build_rocket.py", "sourceIds": ["casc-cz2f"], "license": "自制" },
    { "file": "web/dist/textures/pad-concrete.jpg", "sha256": "…", "role": "scene",
      "depicts": "发射台的混凝土地面", "made_for": "火箭发射",
      "origin": "cc0-library", "how": "ambientCG 按“concrete”搜到的贴图", "license": "CC0" },
    { "file": "web/dist/img/q2-countdown.webp", "sha256": "…", "role": "picture",
      "depicts": "倒计时 10 秒时的火箭和发射塔（第 2 题配图）", "made_for": "火箭发射",
      "origin": "rendered", "how": "从本课三维场景渲染", "license": "自制" }
  ]
}
```

| 字段 | 写什么 |
| --- | --- |
| `file` | 包里的路径（构建后的 `web/dist/…`） |
| `sha256` | 这个文件的校验值（`shasum -a 256 文件`）。验收按它对文件，构建改了文件名也对得上 |
| `role` | `hero` 主角（必须是三维模型）、`part` 主角部件、`scene` 环境、`picture` 题目和讲解配图、`video` 视频、`ui` 界面图标 |
| `depicts` | 画的是什么，写具体（“长征二号F火箭”，不写“模型1”）。主角的 `depicts` 要写出主题里的东西 |
| `made_for` | 为哪个主题做的，等于 `topic`（`ui` 可以不写） |
| `origin` | `modeled` 本次建模、`procedural` 程序生成、`scan` 实物扫描、`cad` 工程图纸、`photo` 实拍、`cc0-library` 免费素材库、`licensed` 有授权、`generated` AI 生成、`rendered` 从本课场景渲染、`drawn` 手绘 |
| `how` / `sourceIds` | 怎么做的、从哪里来（工具、脚本、搜索词、来源条目） |
| `license` | 许可；不知道就写 unknown，不编 |

**产出**：`research/assets.json` 的初稿。这时文件可以还没做出来，校验值做好后再补。

## 第 4 步：按主题做素材

- 清单里的每一项都为这个主题现做、现找。做法、写实要求和返工见 [资产制作流程](asset-production.md) 和 [画面与动画](visual-animation.md)。
- **不复用**：别的课、App 自带场景、本 Skill 示例里的模型、贴图、图片和视频，都不拷过来用。通用代码可以复用，比如 `adw-host.mjs`、three.js，它们不是画面。
- 题目和讲解的配图，从本课自己的三维场景渲染或截图，不另找一张不相干的图。
- 某一项找不到、做不出合格的，写进 `课程设计.md` 的缺口，不拿别的东西顶上。主角做不出来，这节课就不交。

**产出**：每个画面文件都在包里，而且都在清单上。

## 第 5 步：验收，不过就不交

**自动检查。** `scripts/check_package.py` 有 errors 不算做完，App 导入时用同一套规则：

- `exploration.json` 有 `topic`，素材清单的 `topic` 和它一样；
- 网页里每个画面文件（图片、贴图、模型、视频，1 KB 以上）都在清单里，按 sha256 对；
- 每一项写了 `depicts`、`made_for`、`origin`、`how` 或来源、`license`，`made_for` 等于主题；
- 有 `role` 为 `hero` 的三维模型，它的 `depicts` 写出主题里的东西。

清单里出现 App 固定场景的东西（机械臂、齿轮、积木、珊瑚、卷尺、栅栏、地砖……），而主题不是它时，检查会给 warning。确认它真是这个主题里有的，不然删掉重做。

**App 另外查两件事：**

- 包里有画面文件和别的主题的课一模一样，直接拒收，并说是哪节课的。同一个主题的课可以共用。
- 家长端「让 AI 做」的课，素材清单不全或不是为这个主题做的，也拒收。家长手动导入的旧包只在卡片上提示。

**人工检查。** 家长预览时，课程卡片上会列出“主题「火箭发射」的画面：主角是长征二号F火箭（这节课建模）……”。画面像不像真的那个东西，要看真实照片和课里截图的对照，并在 App 里预览。

## 交之前自查（换个主题再问一遍）

- [ ] 把主题换成另一个，这份素材清单还成立吗？还成立，就说明画面不是为这个主题做的。
- [ ] 清单里有没有 App 已有场景的东西，比如机械臂、齿轮、珊瑚、卷尺、积木、栅栏、地砖？有就删掉重做，除非主题本身就是它。
- [ ] 每张题目配图都是从本课场景渲染的吗？
- [ ] 主角是三维模型吗？它的 `depicts` 写的是主题里的那个东西吗？
- [ ] 说明页、讲解和题目里提到的东西，画面上都有吗？

## 三个从没做过的主题怎么走

下表只示范每一步该落到什么，不是这三节课的答案：资料要现查，表里的知识点也要按当时的课内进度再定。

| 步骤 | 火箭发射（妹妹，2 年级） | 蜜蜂（哥哥，4 年级） | 火山（哥哥，4 年级） |
| --- | --- | --- | --- |
| 1 主角和地方 | 一种真实的运载火箭（如长征二号F）；发射场的发射塔、导流槽 | 意大利蜜蜂的工蜂；蜂箱里的巢脾和花丛 | 一座真实的层状火山；火山口、山坡、熔岩流 |
| 2 要查的 | 火箭多高、分几级、几个助推器，倒计时怎么数 | 巢房的形状和大小、一群有多少只、采一趟能带回多少 | 火山多高、坡有多陡、盾状和层状火山的坡有什么不同 |
| 2 学什么（候选） | 倒计时：倒着数、减法；助推器：几个几；火箭和楼比高：米 | 六边形巢房的角：角的度量；一群蜜蜂：大数；采蜜的趟数：乘法 | 火山坡的角度：角的度量；几座火山比高：条形统计图；海拔：大数 |
| 3 素材清单 | 火箭（hero）、发射塔（scene）、发射台地面（scene）、倒计时题配图（picture，本课渲染） | 工蜂（hero）、巢脾（part）、花丛（scene）、巢房题配图（picture） | 火山地形（hero，按公开高程数据）、熔岩流（part）、岩石地面（scene） |
| 不该出现 | 机械臂、齿轮、积木、工厂 | 花园的栅栏和地砖、卷尺 | 海底、珊瑚、积木 |

这三个主题在 App 的测试里各走过一遍：家长端出课 → 自动转成探索课 → 交包 → 验收。素材清单不全、混进别处的图、带着别的课的模型，都会被拒收。测试里的“模型”只是占位字节，不证明画面合格。
