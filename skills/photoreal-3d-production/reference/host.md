# 课末主持人（真人或机器人）

课的最后一步“聊聊”和结束页，由一位主持人带孩子：读问题、听孩子选、点头回应、最后道别。目的是让孩子觉得有人在接待他，而不是对着文字和语音。

## 1. 三种做法（按写实程度排序）

| 做法 | 是什么 | 什么时候用 |
| --- | --- | --- |
| H1 真人视频（默认） | 同一位成人的一组视频片段；说话的片段按每一句台词的配音生成口型 | 默认。家长在家长端选“真人主持” |
| H2 真实机器人视频 | 真实服务机器人的授权实拍，或真实产品模型用路径追踪预渲染的视频 | 家长选“机器人主持”，或机器人主题的课 |
| H3 实时 3D 机器人 | 真实产品的专业或扫描模型（GLB），实时渲染 | 只在模型过了 [realism-spec.md](realism-spec.md) 和 iPad 性能预算时用 |

任何做法都**不能**用代码拼出来的人或机器人，不能用卡通、低多边形、游戏风格、表情包式的脸。现在仓库里的 `packages/components/src/host.js` 就是代码拼的，家长已判定不合格，要换掉（见 [gaps.md](gaps.md)）。

## 2. H1 真人视频的规格

### 形象来源（三选一，家长在家长端选）

1. 家长本人：家长在家长端录一段或上传视频，并勾选同意（记录谁、何时、用于什么）。
2. 有授权的主持人素材：许可要允许生成新的口型（有的素材禁止修改）。
3. 生成的写实人物：依据文字生成、不像任何真实的人，角落标“AI 生成的形象”。

不能用孩子的脸和声音，不能用名人或任何没同意的真人。

### 片段

同一人、同一机位、同一光线、同一服装。每个片段首尾回到同一个中性姿势，方便无缝衔接：

| 片段 | 长度 | 内容 |
| --- | --- | --- |
| idle | 8–12 秒，可循环 | 自然站立或坐着，偶尔眨眼、轻微呼吸，看镜头 |
| listen | 6–10 秒，可循环 | 微微前倾，像在等孩子回答 |
| nod | 1–2 秒 | 点头，表示“听到了” |
| smile | 1–2 秒 | 真诚的微笑（孩子答完时） |
| wave | 2–3 秒 | 挥手道别 |
| speak | 每句台词一段 | 按这句台词的配音生成口型（见下） |

### 说话

- 课里主持人要说的话在发布前就都知道（聊聊的问题、结束语、固定的回应句），审核时由家里的服务器为每一句预先生成说话视频：配音 + 主持人的参考视频 → 口型同步模型 → MP4。按“台词 + 声音 + 形象”的哈希缓存，同一句不重复生成。
- 口型同步可以在家里的服务器本地跑（开源模型，许可逐个核对），也可以用家长同意的云端服务。走云端时只发台词、配音和成人主持人的影像。
- 声音和形象一致：家长本人当主持人时，可以用家长自己的录音或家长同意的声音克隆；其他情况用同一个固定的朗读声音。
- 讲解类台词遵守“一中三英”（`skills/discovery-learning-studio/reference/lesson-flow.md`）。
- 生成不出说话视频时（服务没开、失败），主持人播 listen 片段，台词照常出字幕、朗读。**不要**用一段通用的“说话”循环配别的话，口型对不上一看就假。

## 3. H2 / H3 机器人主持的规格

- 必须是真实存在的服务机器人产品的外形和比例（扫描、厂家资料或专业模型），材质按 realism-spec.md 3.2。
- 只做那个产品真实能做的动作：头部转动、手臂关节（产品本身有才做）、底盘微动、屏幕或灯光变化。说话时的表现就是那个产品说话时真实的屏幕或灯光变化。
- H2 的片段表和 H1 一样（idle、listen、nod、wave、speak），speak 片段的屏幕或灯光按配音的音量包络生成。

## 4. 行为

| 时机 | 主持人 |
| --- | --- |
| 进入聊聊 | 从 idle 开始，读第一个问题（speak） |
| 孩子作答中 | listen |
| 孩子选了或说了 | nod，再读下一题 |
| 最后的心愿题答完 | smile |
| 结束页 | 读结束语，然后 wave |
| 声音关闭 | 不播 speak，只播 idle / listen，字幕照常 |
| 系统开了“减少动态效果” | 显示一张静止的主持人照片，字幕照常 |

- 片段之间交叉淡化 ≤ 300 毫秒，看不出跳帧。
- 口型和声音的偏差 ≤ 80 毫秒。
- 主持人只说课里写好的话，不和孩子开放聊天（BL11）。
- 主持人画面在 Pad 上至少占屏幕宽度的三分之一，不挡问题和选项。

## 5. 接口

播放器（`packages/player/src/main.ts`）现在调用 `mountHost(el)`，用 `talk(on)`、`nod()`、`wave()`。换成下面的接口，播放器同步改：

```ts
interface Host {
  /** 读一句台词：播这句的说话片段并和 audio 对齐；播完 resolve。没有说话片段时播 listen。 */
  speak(line: { text: string; lang: 'zh' | 'en'; audio: HTMLAudioElement | null }): Promise<void>;
  /** 一个反应片段。 */
  react(kind: 'nod' | 'smile' | 'wave'): Promise<void>;
  /** 进入等待回答的状态。 */
  listen(): void;
  dispose(): void;
}
mountHost(el: HTMLElement, opts: { hostId: string; reduced: () => boolean; muted: () => boolean }): Host
```

主持人的片段作为素材登记在资产库（kind 扩展一个 `host`），存放和许可规则见 [asset-sourcing.md](asset-sourcing.md)。

## 6. 隐私

- 主持人素材只存在家里的服务器上。
- 不录、不传孩子的画面和声音；主持人不“看”孩子，不需要摄像头。
- 家长随时可以在家长端删除自己的形象和声音，删除后相关缓存一起删。

## 7. 验收

家长在家长端看一段 30 秒的演示：idle → 说一句中文 → 说一句英文 → listen → nod → smile → wave。家长点“确认可用”后才在课里出现。其余检查见 [acceptance.md](acceptance.md)。
