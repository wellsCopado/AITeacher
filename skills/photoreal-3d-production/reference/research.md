# 做 3D 之前：收集 → 理解 → 整理

先把素材收全、弄懂，最后才整理和挑选。拿搜到的前几张图、第一个模型就开始做，是这个项目里画面不像、主角不对的主要原因。三步按顺序，前一步的产出没写完，不进下一步。

每个主角、环境和道具（场景清单里的每一项，见 [pipeline.md](pipeline.md) P3）都单独走一遍。结果放在 `content/assets/<asset_id>/research/`。

## 第 1 步 收集：先求全，不挑

目的：把这个东西真实的样子、大小、动作、所处环境找全，再找所有可能用的 3D 来源。

| 要收集的 | 最低数量 | 说明 |
| --- | --- | --- |
| 实拍照片 | 15 张，来自至少 3 个不同来源 | 覆盖俯视、正侧、正前、3/4、最有特点的部位特写、在真实环境里（动物在栖息地，机器在车间里工作）、和已知大小的东西放一起（看出尺寸） |
| 实拍视频 | 3 段 | 动作的全过程（动物捕食、游动、出洞；机器人一个完整的工作循环）。记录每段里关键动作的时间点 |
| 事实资料 | 3 个可靠来源 | 图鉴、博物馆、科研论文、百科（有引用的）、厂家数据表。要包括：真实尺寸范围、结构和部件（数量）、材质和颜色、运动方式和速度、所在环境 |
| 3D 来源候选 | 能找到的全部，至少看 5 个 | 按 [asset-sourcing.md](asset-sourcing.md) 的顺序把每一级都搜一遍，不在第一个结果就停。每个候选记：网址、许可、面数、有没有贴图和骨骼、和实拍对比的第一印象 |
| 环境资料 | 5 张照片 + 1 个 HDRI 候选 | 主角真实所处的地方：底质、光线、周围的东西 |

记录在 `research/sources.json`：每条一个来源，`{ type, url, author, license, retrieved_at, what, angle_or_timestamp }`。只记录，先不判断好坏。

找不到最低数量时，写清楚找了哪些地方、用了什么关键词（中文、英文、学名），不要拿相近的东西凑数（例如找不到博比特虫的视频，不能拿别的沙蚕的视频顶替，除非写明“近缘种，仅作动作参考”并经家长同意）。

## 第 2 步 理解：写一份说明，弄懂再动手

读完、看完收集到的东西，写 `research/brief.md`，每节都要有，且每条事实标出处（第 1 步的来源编号）：

1. **它是什么**：名称、学名或型号，一句话说清楚。
2. **真实尺寸**：范围和我们要用的数值，单位米。
3. **结构**：由哪些部分组成，各有几个（足、体节、关节、轮子……），部分之间怎么连接。画一张结构草图或标注一张实拍照片。
4. **外观**：每个部分的材质、颜色、花纹、光泽、透明度、磨损；同种个体之间的差别。
5. **怎么动**：每种动作的过程、速度、用到哪些部位，标出参考视频和时间点。哪些动作真实存在，哪些是我们想象的（想象的不做）。
6. **在哪里**：真实环境、光线、伴生的东西。
7. **孩子会觉得什么有意思**：最值得看的特点（博比特虫从沙里猛地出击、机械臂一个零件不差地摆好），这节课的镜头要对准它。
8. **和这节课的数学怎么连**：数学操作对应它身上或它的环境里的哪个真实东西（几行几个零件、洞口周围的长和宽）。
9. **资料之间的矛盾和不确定**：不同来源说法不一的地方，写出各自的说法；拿不准的标“待科学审核”。
10. **要避免的错误**：常见的画错、做错的地方（例如把某种虫的足数画错、把机械臂的关节转向做反）。

写不出某一节，说明资料还不够，回第 1 步补，不要猜。

## 第 3 步 整理：有了理解再挑选和定方案

`research/plan.md`：

- **参考照片精选**：从第 1 步里挑出用于建模和对照图的照片（每个角度 1–2 张），每张写为什么选它。
- **3D 来源比较**：把所有候选列成表，按写实程度（和实拍对比）、结构是否和 brief 一致、许可、费用、要花的工夫打分，选一个，写清楚为什么不选其他的。都不合格时，写明走“依据照片生成”还是“实拍照片 / 视频展示”。
- **要做的修改**：选中的来源和 brief 不一致或达不到 [realism-spec.md](realism-spec.md) 的地方，逐条列出怎么改。
- **动作方案**：每个动作依据哪段视频、哪个时间点，真实速度是多少，课里要不要放慢、放慢几倍。
- **环境方案**：HDRI、地面、散布物各用什么。
- **对照图的角度**：验收时用哪几张实拍照片做对照（[acceptance.md](acceptance.md) B）。

`plan.md` 写完才开始制作。家长端能看到 `brief.md` 和 `plan.md`（只看，不用确认）；家长有意见的，按意见改了再做。

## 自检

- 第 1 步每一项都到了最低数量，或者写了为什么到不了？
- `brief.md` 十节都写了，每条事实有出处？
- 选 3D 来源前比较了所有候选，不是第一个？
- 每个动作都有真实视频依据？
