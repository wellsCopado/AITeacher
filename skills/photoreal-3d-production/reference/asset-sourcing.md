# 素材来源、许可和登记

## 1. 找素材的顺序

每一项按下面的顺序找，前一级找到合格的就停：

1. **资产库**：`content/assets/registry.json` 里状态为“采用”的素材。
2. **免费授权库**（优先 CC0，其次 CC-BY）：
   - Poly Haven：HDRI、扫描贴图、道具模型（CC0）。
   - ambientCG：扫描贴图（CC0）。
   - Smithsonian Open Access 3D 等博物馆开放数据：标本和文物扫描（多数 CC0，逐个核对）。
   - Sketchfab 上可下载的模型：许可逐个看（CC0、CC-BY、CC-BY-NC 等），只用允许下载和我们用途的。
3. **厂家 CAD 和机器人描述包**：工业机器人厂家官网的 CAD 下载（STEP 等），ROS 的机器人描述包（URDF + 网格）。几何准确但通常没有贴图，要按 [realism-spec.md](realism-spec.md) 3.1 补材质。厂家对 CAD 的使用条款各不相同，逐个核对并登记。
4. **依据真实照片生成**：先找至少 3 张不同角度的真实照片（优先维基共享资源等标明授权的），再用图生 3D 或图片生成，最后由人修整。可用的工具有开源模型（如 TRELLIS、Hunyuan3D）和在线服务（如 Tripo、Meshy、Rodin），代码和模型权重的许可要分别核对（有的权重只许非商用），登记用了哪个、什么版本。
5. **实拍照片或视频**：以上都做不到合格时，用授权的实拍照片或视频展示主角，数学操作放在由真实道具组成的实时场景里。

家长偏好：能不花钱就不花钱。需要付费素材时，先在家长端说明原因、价格、许可，家长同意后再买。

只限某个引擎内使用的素材（例如条款规定只能在某个游戏引擎里渲染的数字人或扫描库），不能导出到网页里用。

## 2. 许可规则

- 许可写不清楚、找不到原始出处、或者是转载的，不用。
- 记录许可原文链接和下载日期。CC-BY 要在家长端素材页和课的出处里署名。
- 非商用许可（CC-BY-NC 等）和家用许可的素材 `commercial_ok: false`，商用前必须替换（校验 V11 / V12 会提醒）。
- 生成类素材：记录服务或模型名、版本、条款链接，参考照片各自的许可也要登记。

## 3. 文件存放

```
content/assets/<asset_id>/
  manifest.json        # 见下面第 4 节
  model.glb            # 主模型（Draco 或 Meshopt 压缩几何，KTX2 贴图）
  model.lod1.glb       # 远景低细节版本（需要时）
  clips/*.mp4          # 预渲染或实拍视频（需要时）
  refs/*.jpg           # 真实参考照片
  sheet.png            # 对照图（自动生成，见 acceptance.md B）
  source/              # 原始下载文件（不进 git，只记 sha256 和网址）
```

- 单个文件超过 20 MB 的不直接进 git：用 Git LFS，或者只把 `manifest.json` 进 git，文件由家里的服务器按网址下载并核对 sha256。
- Pad 通过家里的服务器取文件并缓存，不直接连外网素材站。
- 不再把大素材写成 base64 塞进 `packages/components/assets/assets.js`（那里只留几十 KB 级的小贴图和 HDRI）。

## 4. 登记字段

资产库条目（`content/assets/registry.json`，Schema 在 `packages/schema/schemas/asset.schema.json`）现有字段之外，新的 3D 素材还要登记下面这些（写在 `manifest.json`，实现时同步扩展 Schema）：

| 字段 | 说明 |
| --- | --- |
| `source_url` / `author` / `license_url` / `downloaded_at` | 原始出处、作者、许可原文、下载日期 |
| `generator` | 生成类素材用的服务或模型和版本；不是生成的写 null |
| `reference_photos` | 参考照片：文件、出处、作者、许可、拍摄角度。生成类至少 3 张 |
| `real_scale_m` | 真实尺寸（米），例如 `{ "length": 0.9, "reach": 0.85 }` |
| `subject_facts` | 形态核对依据：例如螳螂虾“步足 3 对、游泳足 5 对”、机械臂“6 个关节”，各带出处 |
| `motion_refs` | 动作依据：真实视频或厂家数据表（关节限位、最大速度） |
| `stats` | 三角形数、材质数、贴图尺寸、文件大小 |
| `checks` | 自动检查结果（见 acceptance.md A） |
| `status` | 待确认 / 采用 / 采用标记 / 拒绝 / 待采购。只有家长在家长端能改成“采用” |

## 5. 隐私

- 发给外部服务（搜索、图片生成、图生 3D、数字人）的只有：主角名称、真实参考照片、成人主持人的授权照片和要读的课文台词。
- 不发孩子的脸、声音、姓名、作业照片、学习记录、孩子说的话。
- 调用云端服务前看家长端的“同意”开关；没打开就停下，在家长端提示家长打开，不偷偷走别的路。
