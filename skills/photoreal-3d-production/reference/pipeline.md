# 从“一个方向和主题”到一节课：系统流程规格

家长在家长端「课程库 → AI 出一节课」只填：给哪个孩子、主题（例如“机器人”“博比特虫”），可选一句方向（例如“想让她明白乘法就是几个几”）。后面全部自动，家长只在最后看结果、点按钮。

每一步的进度显示在家长端这节课的卡片上（一句中文，例如“正在找博比特虫的实拍照片”）。任何一步失败，卡片上写清楚卡在哪、家长能做什么，不让家长去终端。

## 流程

| 步骤 | 做什么 | 谁来做 | 现状 |
| --- | --- | --- | --- |
| P0 心愿 → 准备单 | 孩子课末说了下一次想做什么，马上记下来，生成下一课的准备单，提前开始收集素材 | 服务器自动 | 已有：记下、认主题、排队、家长端显示、动物自动找照片、出课按排第一的、用过标“已安排”。**还要做**：提前收集改成 research.md 的三步（G18）；机器和建筑的素材由 AI 助手按 `adw_next_lessons` 做 |
| P1 定教材位置 | 年级 + 日期 + 家长填的进度 → 上海五四制教材的单元和课时 | 写课模型（`dls context` 给上下文） | 已有；没填进度时按年级和日期推断，标“推断” |
| P2 定数学目标 | 知识点、≤ 3 个误区、选能教它的组件 | 写课模型 | 已有；没有合适组件时要开组件工单（见下） |
| P3 拆场景清单 | 主题 + 数学动作 → 画面里要出现的每样东西 | 写课模型出初稿，素材流程补全 | **要做**：现在只拆出一个主角 `theme.subject` |
| P4 素材解析 | 清单逐项：资产库有就用；没有就找、做、检查、等家长确认 | 素材流程（本 Skill） | 部分：动物有自动找照片 + 画俯视图；机器、建筑、人都没有 |
| P5 写课 | LessonSpec 三份阶段文件、校验、自动修 | 写课模型（`skills/discovery-learning-studio`） | 已有 |
| P6 挑战配图 | 每道题和同类题用课里的场景按题目的数摆一张图 | 播放器 | 已有：`challenges[].picture`（V22、V23）；旧样课还从题目文字里猜数 |
| P7 课末主持 | 聊聊和结束页由主持人带 | 播放器 | 有，但不达标，**要替换**（见 host.md） |
| P8 家长确认 | 课的预览 + 素材对照图放在一处，按钮确认或退回 | 家长端 | 部分：课和素材分在两个页面 |

### P0 孩子说了要做什么，就按它准备下一课

孩子在课末“下一次课你想学什么”里选的或自己说的（最多 20 字），是下一节课最重要的依据（家长另外指定时以家长为准）。

1. **马上记下**：Pad 一提交，服务器就记一条这个孩子的兴趣记录（状态“下一课心愿”，来源“孩子自述”，带课的 id 和日期）。没联网时先存在 Pad 上，联网后补传。已有。
2. **生成准备单**：同时为这个孩子生成一张“下一课准备单”（`apps/server/src/wishes.ts`）：心愿原话（只存在家里服务器）、整理出的主题（孩子的话里有已知主题就用它，认不出时状态“等你确认主题”，家长点一下确认，确认前不发给任何模型或服务）、用哪个现成场景（`themes.json`）、没有场景时要做的主角。家长端「兴趣与心愿」页显示准备单、进度和按钮（现在按它出课、再准备一次、跳过）。已有。还没做：按课内进度推断的数学知识点、场景清单初稿（等 P3 的 `scene_bill`）。
3. **提前收集素材**：准备单一生成，就开始准备这个主题要用的素材，资产库里已有合格素材的跳过。目标是下一次上课前素材已经到“待家长确认”。现在：有现成场景的直接用；没有场景的动物，开了 ChatGPT 账号和同意开关时自动找实拍照片、画写实图（和出课时同一套）；机器和建筑写进准备单，由做素材的 AI 助手通过 MCP `adw_next_lessons` 看到后按本 Skill 做。**要改**：自动收集按 [research.md](research.md) 的收集、理解、整理三步做（G18）。
4. **按准备单出课**：下一节课（家长点“AI 出一节课”或准备单上的“现在按它出课”）默认用排第一的准备单的主题，上下文 `next_lesson_wish` 给出它；课交上来时服务器在 `parent_tip` 补一句“按哥哥 10月25日的心愿「螳螂虾」准备。”（只写主题，原话只在家长端准备单上显示）。写课规则见 `skills/discovery-learning-studio`。已有。
5. **多个心愿排队**：一个孩子有几条没用过的心愿，按时间先后排队，用过的标“已安排”，家长跳过的标“已跳过”（都还留在兴趣里）。同一个主题还在排队时又说了一次，不重复排，记在那张准备单上。孩子连续 3 次选同一个主题，照样按它准备，只在心愿问题里轻轻提议换一个。已有。
6. **隐私**：心愿原话只存在家里服务器；发给外部模型和服务的只有整理出的主题名称。

### P1 不停下来要资料

- 上下文里 `school.progress` 有就用；没有就按年级和日期推断单元，在 `parent_tip` 写“推断：…，家长可在「兴趣与心愿」页的“课内数学进度”里改”。
- 不问家长要教材、“沪学习”截图或单元名称。家长愿意上传教材页照片时，只在家里服务器上用，按作业照片同样的同意开关处理。

### P2 没有合适组件时

数学目标需要的交互现有组件做不到（例如四年级的角的度量、大数的认识），这节课不硬套别的组件。写课模型输出“需要新组件”的说明（知识点、要孩子做的动作、要看到的东西），家长端显示一张“组件工单”，由实现画面的 agent 按 [component-contract.md](component-contract.md) 做。

### P3 场景清单的格式

```json
{
  "items": [
    { "id": "robot", "role": "主角", "what": "六轴工业机械臂（真实型号）", "kind": "machine",
      "real_scale_m": { "reach": 0.85 }, "views": ["3/4 前侧", "抓取特写"], "motion": "抓取 → 移动 → 放下，一行一行",
      "realism": "cad" },
    { "id": "gears", "role": "道具", "what": "钢和黄铜的直齿轮，直径 10 cm", "kind": "part", "count": "rows × cols",
      "realism": "cad" },
    { "id": "cell", "role": "环境", "what": "工厂车间：混凝土地面、安全围栏、传送带", "kind": "environment",
      "realism": "scan" },
    { "id": "labels", "role": "数学标注", "what": "行、列、总数标签", "kind": "overlay" }
  ]
}
```

清单进 `02-director.json` 的 `scene_bill`（实现时扩展 Schema 和校验），每一项要么对应资产库的“采用”素材，要么进 `pending`。

### P4 素材解析

- 每项先按 [research.md](research.md) 收集、理解、整理，写完 `brief.md` 和 `plan.md` 再按 [asset-sourcing.md](asset-sourcing.md) 取得或制作。每项单独一个后台任务，和写课并行；来自准备单（P0）的，在上课前几天就开始。
- 动物：现在服务器会让 ChatGPT（经 Codex）找 3–4 张实拍照片、查体长、画一张俯视写实图，再自动切节做成 2.5D 浮雕。这只是过渡方案，要换成真三维（见 gaps.md）。
- 机器和机器人：从厂家 CAD 或授权模型开始，按 realism-spec.md 3.1 补材质和运动学。
- 做好的素材状态“待确认”，家长确认前孩子看不到。课里这个素材没确认时，这节课不能发布（V19）。

### P6 挑战配图写明数（已做）

以前播放器从题目文字里找“几行”“每行几个”“长”“宽”来摆图，写法稍有变化就摆错。现在：

- LessonSpec 每道题和它的 `twin` 加 `picture`：`{ "params": { … 组件参数 … }, "view": "<相机预设名>" }`，校验时用组件的参数范围检查，并检查图里的数和题目、答案一致。
- 组件提供 `still(params)`：直接摆出这个参数下的完成状态（不播动画），相机用 `view` 指定的预设。
- 题目和配图用同一个场景、同一套素材；不带主题的迁移题也用这节课的场景，不退回积木。
- 写法见 `skills/discovery-learning-studio/reference/challenge-types.md` 第 5 节。相机预设现在有 `overview`、`top`、`side`；新皮肤或新组件要支持这三个，可以加自己的预设，加了就在 `components.json` 和 Schema 里登记。

## 失败时怎么办

| 情况 | 处理 |
| --- | --- |
| 主角的写实 3D 做不出来（试了 2 种来源都没过家长确认） | 主角用授权实拍照片或视频展示；数学操作用真实道具的实时场景；家长端说明 |
| 连实拍照片都没有 | 这节课等着，不发布；家长端提示可以自己上传照片 |
| 云端服务没开同意开关或没登录 | 停在这一步，家长端提示去哪里打开 |
| 数学目标没有合适组件 | 出组件工单（见 P2），这节课等组件 |
