# 判断校验 J01–J09

`dls homework check` 和服务器提交时都会跑。✗ 为错误（不能提交），! 为警告。

| 规则 | 检查 | 常见修法 |
| --- | --- | --- |
| J01 | 结构完整（judgment.schema.json） | 按报错路径补字段；`facts`、`next` 至少一条 |
| J02 | 只引用家长核对过的题 | 题号用识别结果里的 `no`；等家长核对完 |
| J03 | 不评价孩子本人、不保证成绩（BL07） | 把“粗心、马虎”换成具体行为；删掉“保证、提分” |
| J04 | 推测写成推测 | 用“可能…”，置信度 ≤ 0.9，写依据题号和验证方式 |
| J05 | 掌握状态与证据相符 | 作业里做对 → 有独立应用证据；只有课内答对 → 待确认；做错/半对 → 需再支持 |
| J06 | 需再支持要有重教建议 | `next` 加 `{ kind: "重教", concept_id, text }` |
| J07 | 知识点在知识点表里 | 用 `content/concepts.json` 的 id 和它的误区 id |
| J08 | 更正旧推测 | `corrects` 指向已确认的判断和存在的 gap 序号 |
| J09 | 事实不夹带推测（警告） | “可能、也许、大概”移到 gaps 或家长卡“还没验证的解释” |

## 掌握状态

| 状态 | 什么时候 |
| --- | --- |
| 未观察 | 还没有任何证据 |
| 待确认 | 只在课内答对，或证据还不够 |
| 有独立应用证据 | 之后的真实作业里独立做对 |
| 需再支持 | 作业里做错或半对，且家长核对过 |

家长端“掌握与重教”页按知识点显示最新状态：最近一次已确认的判断优先，没有判断时课内答对显示“待确认”。
