# 兴趣 → 主题 → 场景

映射表：`content/themes.json`；兴趣记录：`content/interests.json`；孩子档案：`content/children.json`。

选择顺序：家长指定 > 这个孩子的“下一课心愿” > “近期最喜欢” > “喜欢”，同级取最新。家长在「主题」框里写的，或者在要求里说的（“写一个蟋蟀的课程”“用大桥做主题”），都算家长指定。

## 有专门场景的主题

| 兴趣 | 场景 | 状态 |
| --- | --- | --- |
| 螳螂虾、海底、海洋动物 | reef 珊瑚礁样方调查（PerimeterArea） | 已有 |
| 机器人、机械臂、工厂、齿轮 | robot_factory 机械臂一行一行摆齿轮（ArrayMultiplier） | 已有，写实版制作中，替换前不发布 |
| 昆虫、蟋蟀、蚂蚁、蝴蝶、螳螂…… | insect_meadow 草地昆虫样方 | 待开发 |
| 高楼 | tower_floor 楼层平面 | 待开发 |
| 大桥和隧道 | tunnel_walkway 隧道检修通道 | 待开发 |
| 机器人 | robot_vacuum 扫地机器人 | 待开发 |

中性题材（没有主角）：PerimeterArea 用 garden，ArrayMultiplier 用 blocks。

## 没有专门场景时：按主角生活的地方选（V24）

家长指定或孩子心愿的主题还没有专门场景时，它就是这节课的主角（`theme.subject`）。系统按它住在哪里选场景，模型不能换。

1. 先看主角住在哪里：`habitats` 里哪个词出现在名字里，最长的那个算（“小龙虾”算河湖，不算“虾”的海里）。都没有时，动物和植物算野外，机器和建筑算院子。
2. 再找这个组件里同一个地方的现成场景。

| 住的地方 | 例子 | 现成场景 |
| --- | --- | --- |
| 海里 sea | 螳螂虾、博比特虫、章鱼、海蛞蝓 | reef 珊瑚礁（主角在沙里的洞口出现） |
| 院子和草丛 yard | 蟋蟀、蚂蚁、蝴蝶、螳螂、蜗牛、刺猬、花草 | garden 花园（主角用实拍照片和视频出现） |
| 河湖池塘 fresh | 金鱼、小龙虾、青蛙、娃娃鱼 | 还没有 |
| 野外 wild | 狮子、大象、熊猫、鳄鱼、恐龙，以及认不出的动物 | 还没有 |
| 城市 city、天上 sky、港口 harbor、家里 home | 大桥、上海中心、火箭、船、扫地机器人 | 还没有 |
| 工厂 factory | 机械臂、齿轮 | robot_factory |

blocks 积木只有积木（habitat none），不放任何主角：一节讲金鱼的课不能只是积木加上“金鱼”两个字。

3. 哪个组件都没有这种场景时，系统不写这节课。家长出课时会看到“「金鱼」生活在河湖池塘，课里还没有这样的 3D 场景”，心愿准备单上也这样写。家长端会给一个按钮，一键改成探索课：家里 Mac 上的 Codex 按 `skills/discovery-lesson-maker` 自己建它住的环境。也可以开新场景工单。

每个现成场景里画面上有什么，写在 `shows` 里，上下文的 `themes_ready[].shows` 也有。讲解和题目只说画面上有的东西，见 [writing.md](writing.md)。

## 加一个新的场景或动物

- 新动物住的地方认错了，在 `habitats` 对应的 `words` 里加上它的名字。
- 新场景做好后，在 `skins` 里写上 `habitat`、`shows`，`status` 改成“已有”。

同一主题连续 3 节后，工具会提示在心愿问题里鼓励换一个，但孩子可以继续选。
