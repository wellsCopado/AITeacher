# 把课写好：主角、场景和数学是同一件事

家长的反馈：

- 2026-11-04：让 AI 写一节蟋蟀的课，演示里却是海底。“蟋蟀怎么会生活在海底呢，这个课程完全写的不对”“环境不对，课程写的不好”。
- 2026-11-05：给妹妹写火箭发射，“结果就改了文字，图片还是机器臂”“写啥主题就做啥图片啊，不要总是复用原来的素材”。

校验通过只说明格式对，不说明课好。下面这些写课前想清楚，交之前逐条自查。V24、V25、V27 会拦下最明显的错，其余靠你。

## 0. 先看这个主题能不能写成参数课

参数课的场景是现成的，只能讲场景画着的东西（`themes_ready[].depicts`，V27）：

- 珊瑚礁：螳螂虾、珊瑚礁海底；
- 花园：栅栏和地砖；
- 积木：积木；
- 机器人工厂：机械臂摆齿轮。

家长要的主题不在里面时（火箭发射、蜜蜂、火山、蟋蟀……），系统会自动把它做成探索课，按主题自己建场景、做图。你不写它，也不要只改文字，把旧场景说成它。家长的退回意见要换成场景里没有的主题时，同样如此。

## 1. 先弄清主角，再动笔

- 主角真实长什么样、多大、住在哪里、靠什么活（吃什么、怎么动、怎么叫或怎么捕猎）。挑 1–3 条孩子听得懂、又和今天的数学有关的，写进讲它的热点的 `facts`，每条 `ref` 写出处；查不到出处就写“待科学审核”，不编。
- 场景由系统选好（`suggested_theme.skin`，见 [themes.md](themes.md)），它一定画着这节课的主角，原样用，不要换。
- 现成场景都没画它时，系统把它做成探索课，不写参数课。不要换一个不相干的场景凑数。

## 2. 数学从主角的世界里长出来

- 找一件在主角的世界里真的会发生的测量或数数：生物学家用样方数洞、数虫子，园丁量栅栏、铺地砖，工程师量隧道，工厂按行摆零件。不写不会发生的事（“蟋蟀铺地砖”“鱼在积木上排队”）。
- 数字合乎真实比例：蟋蟀身长约 2–3 厘米（待科学审核），一块观察区几米见方；一只虫子不会占 10 平方米。
- 至少一处让孩子把主角的真实大小和场景里的米、平方米比一比。示例课里是“它的身长和 1 米的样方边相比，差多少”。

## 3. 一条故事线

标题、说明页、演示、预测、题目、鼓励讲的是同一个地方、同一件事。

- 说明页第一段：孩子要去哪里，看到主角在做什么，为什么要量或要数。
- 第二段：点出今天要分清的两个量（一圈和铺满，几行和每行几个）。
- 带主题的题（`with_theme: true`）沿用这个情境。迁移题明说“换一个地方”，不带主角。
- `encouragement.persist` 用主角或这个场景里的人做比喻，和前面讲的事实一致。

## 4. 说的都要看得到

`themes_ready[].shows` 写着每个场景里有什么，讲解和题目只说画面上有的东西。

- 珊瑚礁（reef）里是黄色卷尺和白色 PVC 样方框。
- 花园（garden）里是测距轮、木栅栏和 1 米见方的石板地砖（按钮叫“铺地砖”）。
- 积木（blocks）里只有积木。

不要在花园里说“卷尺”“样方框”“潜水”，不要在积木上说“机械臂”。V26 会拦下别的场景才有的东西，英文那 3 条也算。

讲主角的热点用 anchor `shrimp`。这个名字是历史原因，讲的是这节课自己的主角，不是螳螂虾。

- 在珊瑚礁里，它指着主角的洞。
- 在别的场景里，孩子点它时播放器打开主角的实拍照片和视频。讲解写成“来看看真实的它”，不说“看它的洞”，场景里也不会有它的 3D 模型（写实底线，不用替身）。

## 5. 示例课只借结构

示例课 `L-PA/1.1` 讲的是螳螂虾和珊瑚礁海底。字段、层级、类型照它，内容一个字也不抄。

- 主角不是螳螂虾时，不出现螳螂虾。
- 主角不住在海里时，不出现海底、珊瑚、潜水。

V24 会拦下这两种情况。

## 6. 写给孩子听

- 句子短，能读出来，一句只说一件事。先说看到的，再说道理。
- 问“哪个是一圈、哪个是铺满”，不问“你懂了吗”。
- 英文 3 条讲的也是主角和这个场景，不是示例课的英文换个词。

## 例子：家长说“给妹妹写个火箭发射的课程”

| | 不行（2026-11-05 退回的） | 可以 |
| --- | --- | --- |
| 走哪条路 | 套机器人工厂场景，把文字改成火箭 | 现成场景没有火箭，系统交给 ChatGPT（Codex）做成探索课 |
| 画面 | 机械臂一行一行摆齿轮 | 按主题新做：火箭的三维模型、发射塔、发射台，题目配图从这节课的场景渲染 |
| 标题 | 火箭发射：机械臂装零件 | 由探索课按调研定，例如“发射场倒计时：火箭有几个助推器” |
| 验收 | V27：标题和说明讲火箭，场景里没有火箭 | 素材清单里每一样都写明“为火箭发射做”，App 核对后才收 |

## 例子：螳螂虾在珊瑚礁（场景画着它，可以写成参数课）

| | 不行 | 可以 |
| --- | --- | --- |
| 说明页 | 潜到海底，去找螳螂虾，再看看旁边的鲸鱼。 | 珊瑚礁边的沙底上有个洞，螳螂虾就住在里面。我们沿着调查区拉一圈卷尺，再用 1 米见方的样方框铺满。 |
| 讲主角的热点 | 螳螂虾是一种大虾。 | 来看看螳螂虾：它的捕肢出拳很快（待科学审核）。它的身长和 1 米的样方边比，差多少？ |
| 题目 | 新的调查区长 5 米、宽 3 米，测距轮沿栅栏走一圈是几米？（花园才有测距轮） | 新的调查区长 5 米、宽 3 米，卷尺拉一圈是几米？ |

## 交之前自查

- [ ] 把主角的名字换成别的动物，这节课还照样成立吗？成立就说明主角只是贴上去的，重写。
- [ ] 场景画着这节课讲的东西吗？标题写的是场景里的东西吗？（V27）
- [ ] 场景是主角真正生活的地方吗？
- [ ] 关于主角的每条事实都有出处或“待科学审核”吗？
- [ ] 讲解和题目里提到的工具、东西，画面里都有吗？
- [ ] 数字合乎真实比例吗？
- [ ] 题目的情境和说明页是同一件事吗？
- [ ] 有没有一句来自示例课的螳螂虾、海底、卷尺、样方框，而这节课里没有它们？

## 现有组件做不好的课

参数课只有两种 3D 组件：PerimeterArea 只教周长和面积，ArrayMultiplier 只教乘法的意义。家长想讲的东西和这两种数学都连不起来，或者需要它自己的 3D 场景和动画时（蟋蟀怎么叫、螳螂怎么捕食），这不是参数课能做好的。

- 主题本身场景里没有的，系统已经自动转成探索课，你不会收到这种请求。
- 主题在场景里、但想讲的东西组件做不到时：在 `parent_tip` 里说清这节课只能讲到哪里，建议家长在「课程库 → 探索课 → 让 AI 做一节探索课」写上主题。家里 Mac 上的 ChatGPT（Codex）会按 `skills/discovery-lesson-maker` 先查该学什么，再自己建场景、做成整节网页课。
- 或者请做素材的 agent 开新场景工单，例如 `insect_meadow` 草地昆虫样方，现在是待开发。做好后在 `themes.json` 写上它的 `depicts`。
