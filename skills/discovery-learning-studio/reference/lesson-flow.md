# 孩子上课的固定流程（家长定的规则，不能改）

Pad 播放器按下面的流程跑每一节课。流程本身写在播放器里，课程不能关掉它；但流程里孩子听到、看到的话，很多要由你在 LessonSpec 里写好。下面每一条都写了“你要写什么”。

## 1. 四步，按顺序，一步一步解锁

说明 → 互动演示 → 挑战 → 聊聊（可跳过）。

- 上一步没做完，下一步的按钮是锁着的，孩子不能直接跳到 3D 或自己喜欢的部分。
- 演示里的几件事也按顺序：当前这件事的按钮在闪，后面的按钮先锁着。
- 每一步、每件事、每道题都有倒计时。时间到了自动进入下一件事或下一步，最后一步时间到就结束这节课。没有人会卡在一个地方。
- **你要写**：`learner_profile.est_minutes`；需要时用 `timing.steps` 给某一步指定秒数（V16）。说明页、提示、题目都要短，孩子 1 分钟内能听完。

## 2. 题目和文字自动出字幕、自动朗读

说明页每一段、每道题、每条提示和反馈，都会出字幕并读出来。孩子点“开始上课”那一下同时打开声音（iPad 要求先点一下才有声音）。

- **你要写**：一句话一个意思，适合读出来；不要用表格、括号套括号、特殊符号。

## 3. 讲解固定“一中三英”

每个热点按“中文 1 条 → 英文 3 条”循环讲解，没有纯中文模式（V05）。

- **你要写**：每个热点 `language_pack` 写中文 1 条、英文 3 条，英文短、准确、不加门槛。

## 4. 夸奖：具体、真实，给孩子情绪价值

播放器每次判题后都会说一段话，结构固定是 **先夸做对的地方 → 再说要看哪里 → 再给坚持的理由**。

- 做对了：按孩子是怎么做对的来夸。
  - 一次就对：夸“先想清楚再写”的习惯。
  - 用了提示才对：夸“自己想通了”。
  - 错过再对：夸“没有放弃”。
  - 看了演示后自己做对：夸“马上就会用了”。
- 做错了：**一定先找出真正做对的部分来夸**，例如“周长完全做对了”“数算对了，只差单位”“单位选对了，说明你知道它在量什么”。什么都不对时，夸他动手试了、敢于做选择。然后说要再看哪里（只说事实），最后给一个坚持下去的理由。
- 不说空话（“你真棒”“加油”这种单独出现不算）；不打分、不排名、不和别人比（BL10）。
- **你要写**：`encouragement.persist`，2–5 句，答错时用来给孩子坚持的理由，最好和这节课的主题相连（V18）。

好的例子（螳螂虾主题）：

- “螳螂虾的洞也是一点一点挖出来的，我们再挖深一点！”
- “海洋科学家量错了就重新量，这正是他们靠谱的地方。”

不行的例子：“你真棒！”“加油！”“再想想。”（孩子听不出为什么要坚持）

## 5. 同一道题错三次：先演示一遍，再让孩子自己做一道同类题

- 第 1 次错：夸做对的部分 + 说要看哪里 + “再试一次”。
- 第 2 次错：同上，并自动给出下一级提示。
- 第 3 次错：播放器说“我们一起看一遍怎么做”，然后把 `worked_example.steps` 一步一步显示、出字幕、朗读，最后一步把正确答案填进答题框。演示时不扣这道题的时间。
- 演示完：出现“轮到你自己做一次”，给出 `twin` 这道同类题，孩子独立作答一次。做对了大力夸；还没做对，也先夸做对的部分，再告诉他答案，说“方法你已经看懂了，下次一定能自己做出来”。然后进入下一题，不会无限重试。
- 家长端学习记录会写清楚：试了几次、用了几级提示、有没有看演示、同类题有没有自己做对。
- **你要写**（每道题都要，V17 是错误级）：
  - `worked_example.steps`：2–5 步，每步一句孩子听得懂的话，像老师在旁边边做边说；**最后一步必须说出所有答案**（数和单位）。
  - `twin`：同一个方法，换数字或换情境；`answers` 的 `field` 和原题一模一样；原题是选择题，同类题也写 `options`，答案在选项里。不能和原题一样（孩子要自己用一遍方法，不是照抄答案）。

## 6. 课末必问心愿

聊聊这一步最后一定问“下一次课你想学什么”，选项来自这个孩子自己的兴趣，允许自己说（V14）。孩子选的会自动记到家长端。
