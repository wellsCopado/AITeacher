# 发布前审核清单（家长确认）

四类全部确认才能发布。每类确认后运行 `dls review <目录> --approve <类别> --by <家长称呼>`。

**科学**
- 定义和单位正确
- 示意已标注、无虚构结构
- 画面写实，无卡通或简化生物（BL14）

**教研**
- 教材映射状态正确
- 迁移题不带原题材
- 主题来自孩子自己的兴趣
- 每道题的分步演示算得对、说得清，最后一步给出答案
- 同类题用的是同一个方法，但不是照抄原题
- 鼓励坚持的话具体、和主题相连，不是空话

**语言**
- 中文讲解适龄、准确
- 英文 3 条准确，不增加门槛

**安全**
- 离屏任务需成人陪同、无危险
- 无开放聊天、无外链
