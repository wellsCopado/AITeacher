# 挑战题的题型

家长的要求（2026-10-25）：挑战题以**选择题**和**应用题**为主，少出填空；要有孩子动手的**操作题**（点一点、滑一滑、拖过去组装）。

## 每节课的搭配（2–3 道）

| 题型 | 数量 | 现在能不能写 |
| --- | --- | --- |
| 选择题 | 至少 1 道 | 能：写 `options` |
| 应用题 | 至少 1 道（可以同时是选择题） | 能 |
| 动手操作题（`task`） | 组件支持时每节至少 1 道 | 能：PerimeterArea、ArrayMultiplier 的“摆一摆”（见下面第 4 节）；V20 提醒、V21 检查 |
| 填空题（没有 `options` 也没有 `task`） | 最多 1 道 | 能，但尽量少 |

新写的课不符合这个搭配，校验 V20 报错，交不上去（只有题型规则之前写的两节样课 L-PA@1.0、L-ARR@1.0 只是提醒）。照着示例课 `content/lessons/L-PA/1.1/` 写：选择题 + 应用题、动手题、不带主题的选择题，每道都有配图。

不带主题的迁移题（`with_theme: false`，V09）也算在里面，最好也写成选择题。

## 1. 选择题

- 2–4 个选项（是非题 2 个，其余 3–4 个）。
- 每个错误选项对应一个真实的误区（这节课 `misconceptions` 里的，或这个年级常见的），例如周长面积课里把周长和面积弄混得到的数、乘法课里把行数和列数加起来得到的数。不要用随便编的数凑选项。
- 不用“以上都对”“以上都不对”。
- 选项短，能读出来；数字带单位时，单位也写进选项（“16 米”）。
- `answers` 只有一个，值和正确选项一字不差；同类题 `twin` 也写 `options`（V17）。

## 2. 应用题

- 情境来自这节课的主题和场景里真实发生的事：机械臂一次摆一行、调查员拉卷尺围样方、博比特虫的洞口周围铺沙。数字合理（真实尺寸、真实数量）。
- 二年级：一步就能算出来，题目里的数不超过这个单元的范围。四年级：一到两步，可以有一个多余的条件让孩子挑。
- 问清楚问的是什么（“一共要几个齿轮”“需要多长的卷尺”），单位明确。
- 可以写成选择题（推荐），也可以要孩子填一个数和单位（算这节课唯一的填空题）。
- 题目里写清“几行、每行几个”或“长几米、宽几米”，播放器按这些数给题目配图。

## 3. 填空题

只在必须让孩子自己写出一个数时用（例如“写成乘法算式”），每节最多 1 道。纯计算题（只有算式没有情境）尽量不出。

## 4. 动手操作题

孩子在 3D 场景里亲手摆：拖场景角上的蓝色把手 ⤡，或者点题目下面的 −/＋，把场景摆成题目要求的样子，摆对了就算答对。场景角上实时显示现在摆成了什么（“现在：长 5 米，宽 3 米”“现在：3 行，每行 4 个，一共 12 个”）。

### 现在能写的：摆一摆（`type: "build"`）

| 组件 | 孩子能改的参数（`controls` 从这里选） | 范围 | 答案单位 |
| --- | --- | --- | --- |
| PerimeterArea | `a` 长、`b` 宽 | 1–10 | 米 |
| ArrayMultiplier | `rows` 几行、`cols` 每行几个 | 1–9 | `rows` 用“行”，`cols` 用“个” |

组件能做哪些动手题，以 `dls context` 里每个组件的 `hands_on` 为准（来自 `content/components.json` 的 `handsOn`）。

```json
{
  "id": "c1", "with_theme": true,
  "prompt": "调查员要围一块周长 16 米、面积 15 平方米的调查区，长比宽长。拖角上的把手，把调查区摆出来。",
  "task": { "type": "build", "start": { "a": 2, "b": 2 }, "controls": ["a", "b"] },
  "answers": [{ "field": "a", "label": "长", "value": 5, "unit": "米" }, { "field": "b", "label": "宽", "value": 3, "unit": "米" }],
  "worked_example": { "steps": ["周长 16 米，长和宽加起来是 16 的一半：8 米。", "8 可以分成 5 和 3，5 × 3 = 15，面积正好。", "所以长 5 米、宽 3 米。"] },
  "twin": {
    "prompt": "再围一块周长 14 米、面积 12 平方米的调查区，长比宽长。",
    "task": { "type": "build", "start": { "a": 1, "b": 1 }, "controls": ["a", "b"] },
    "answers": [{ "field": "a", "label": "长", "value": 4, "unit": "米" }, { "field": "b", "label": "宽", "value": 3, "unit": "米" }]
  }
}
```

规则（V21 会检查，不对就报错）：

- `start` 写全这个组件能改的所有参数（PerimeterArea 写 `a` 和 `b`，ArrayMultiplier 写 `rows` 和 `cols`），都在范围内的整数。
- `controls` 是孩子能改的参数，只能从上表里选；只让孩子改一个时，另一个固定在 `start` 里（例如“每行 4 个不变，摆出 12 个”：`start: {rows: 1, cols: 4}`，`controls: ["rows"]`，答案 `rows = 3`）。
- `answers` 正好一个 control 一条：`field` 就是参数名，`value` 是要摆成的数（范围内整数），`label` 写孩子看得懂的词（长、宽、几行、每行几个），`unit` 按上表。
- `start` 不能已经等于答案（孩子要真的动手）。
- 动手题不写 `options`。
- `twin` 也写 `task`，换数字或换情境；`twin.start` 最好和原题不同。
- `worked_example` 照常写，最后一步说出答案的数。孩子错 3 次时，场景会自己一格一格摆到答案，同时朗读这些步骤，然后给同类题。

### 怎么出好的动手题

- 让孩子“摆”出一个数学条件，而不是照着数字摆：“周长 16 米、面积 15 平方米”比“摆成长 5 宽 3”好；二年级可以直接说“摆成 3 行，每行 4 个”，再问“一共几个”留给选择题。
- 答案只能有一个。“周长 16 米”有好几种长宽，要再加一个条件（面积、或者“长比宽多 2 米”）；播放器按参数判对，长 3 宽 5 和长 5 宽 3 是不同的答案，所以题目里写清“长比宽长”，或者固定一个参数只让孩子改另一个。
- 情境用主题：调查员围样方、机械臂摆一行一行的齿轮。
- 每道动手题至少给 60 秒（播放器自动保证）。

### 以后会有的

点选（点出第 2 行的所有齿轮）、拖放组装（把齿轮一个个拖进托盘）、旋转（把托盘转 90°）还没有做。组件支持后会在 `hands_on` 里出现新的 `type`，这里会写清格式；在那之前只写 `build`，别的 `type` 校验会报错。

## 5. 配图（`picture`）

每道题都配一张图：用这节课的 3D 场景，按题目里的数摆好（不播动画），孩子可以转着看。不是动手题的每道题和它的 `twin` 都写：

```json
"picture": { "params": { "a": 5, "b": 3 }, "view": "overview" }
```

- `params` 用组件的参数名：PerimeterArea 写 `a`（长）、`b`（宽），ArrayMultiplier 写 `rows`（几行）、`cols`（每行几个），在组件范围内的整数（V22）。
- 只摆**题目给出的数**，不要把答案摆出来（问“一共几个”时摆 3 行 4 个可以，问“要摆几行”时就别摆出行数）。配图里的每个数都要在题目里出现（V23）。
- `view` 可选：`overview` 斜看全景（默认）、`top` 正上方俯视（数格子、看面积时好用）、`side` 侧面。
- 场景里的标注是米：题目和选项也用米、平方米，不要场景标“长 7 米”、题目说“7 厘米”。
- 不带主题的迁移题（`with_theme: false`）也用这节课的场景配图，不退回积木。
- 动手题不写 `picture`：场景从 `task.start` 开始，孩子自己摆。

新写的课缺配图或配图的数题目里没有，V23 报错；样课 L-PA@1.0、L-ARR@1.0 是这条规则之前写的，播放器还会从题目文字里猜数给它们配图。
