# 产品原则摘要（基线 V1.2）

完整原文：`docs/产品原则与需求基线_V1.2.docx`。冲突时以基线为准。

| 编号 | 原则 | 对制作的直接要求 |
| --- | --- | --- |
| BL01 | 数学目标优先 | 先定知识点和误区，再选主题 |
| BL02 | 交互解释关系 | 每个动作和热点写 `teaches`；参数改变有计算依据 |
| BL03 | 数学科学准确 | 数值、单位、来源可追溯；简化只用于 2D 图示和结构分层 |
| BL04 | 上海教材参考 | 未核对不标“已核对本年级” |
| BL05 | 兄妹各自设计 | 各自的兴趣、路径和证据；妹妹不套用哥哥的兴趣 |
| BL06 | 英语绝不强制 | 不考英语；讲解按家长要求固定“一中三英”（V05），英文缺失时回落中文 |
| BL07 | 作业判断与重教 | 重教换表征或教法，用新题验证 |
| BL08 | 反馈分源保留 | 事实、解释、推测分开 |
| BL09 | 简短成长支持 | 课末 2–4 分钟、可跳过 |
| BL10 | 事实鼓励与沟通 | 夸奖具体、有依据：答错先夸真正做对的部分，再说要看哪里，再给坚持的理由；不说空话、不打分、不签到扣分 |
| BL11 | 隐私与安全 | 不开放聊天、不外链；枪械兴趣只转安全工程题材 |
| BL12 | 内容生产与轻量交付 | 不做养殖或经营 |
| BL13 | 当天与父母授权 | 只开当天的课 |
| BL14 | 写实底线 | 所有 3D 写实；生物只用扫描、实拍或依据照片的 AI 生成；未到位不展示，不用卡通或简化模型代替 |

兴趣：哥哥的兴趣会轮换（螳螂虾、昆虫、高楼、大桥隧道、机器人……），以兴趣记录为准；每节课末问“下一次课你想学什么”。
