# 部署家里的服务器

服务器一个进程同时提供：内容接口（`/v1/…`）、孩子用的 Pad 轻 App（`/pad/`）、家长端网页（`/parent/`）。数据存在一个 SQLite 文件里。

## 放在哪里

| 方式 | 适合 | 说明 |
| --- | --- | --- |
| 家里一直开着的电脑或 NAS | 先家用 | 数据不出家门；Pad 和服务器在同一个 Wi-Fi 下 |
| 一台小云主机 | 在外面也想用、以后商用 | 需要域名和 HTTPS；每行数据已带 `tenant_id`，以后可以分家庭 |

## 方式一：Docker（推荐）

```
docker build -t adw .
docker run -d --name adw -p 8787:8787 \
  -e ADW_PIN=你的家长PIN \
  -v adw-data:/app/data --restart unless-stopped adw
```

## 方式二：直接用 Node（需要 Node 22.5 以上）

```
pnpm install
ADW_PIN=你的家长PIN pnpm start
```

## 第一次使用

1. 电脑上打开 `http://<服务器地址>:8787/parent/`，输入 PIN。
2. 孩子的 iPad 用 Safari 打开 `http://<服务器地址>:8787/pad/`，屏幕上会出现 6 位配对码。
3. 家长端“设备”页输入配对码、起个名字（比如“哥哥的 iPad”），点批准。iPad 几秒内自动连上。
4. iPad 上点分享 → “添加到主屏幕”，以后像 App 一样打开。

## 发布课程和排课

课程在本仓库里用 Skill 做好、家长审核后：

```
ADW_PIN=你的家长PIN pnpm -s dls publish content/lessons/L-PA/1.0 --server http://<服务器地址>:8787
```

服务器会用自己的兴趣记录再跑一遍 V01–V15，并核对内容哈希和四类审核，任何一项不过都会拒绝。然后在家长端“排课”页勾选日期，孩子当天就能看到；想让孩子提前或补做，用“课程库”页的临时授权（1–7 天）。

孩子在课末说的“下一课想学什么”会自动记进家长端“兴趣与心愿”。做下一节课前同步回来，Skill 会优先用它：

```
ADW_PIN=你的家长PIN pnpm -s dls sync --server http://<服务器地址>:8787
```

## 作业判断

1. 家长端“作业”页上传照片（一次最多 8 张，浏览器里先压缩）。想让 Claude 识别就勾选“同意用 Claude 识别”。
2. 在本仓库里用 Claude Code 说“看看今天的作业”。Skill 会下载照片、逐题识别并上传。
3. 家长在“作业”页逐题核对（标“请核对”的题必须单独看），识别错了直接改。
4. Skill 写判断；家长看过后点“确认”。“需再支持”的知识点会生成重教需求，在“掌握与重教”页能看到。
5. 说“按重教需求做一节课”，Skill 会换一种教法重做；下一次作业再判断，独立做对了重教需求自动标“已验证”。

作业照片存在数据目录的 `homework/` 下（默认 `data/homework/`），不进数据库，也不出这台机器；Skill 识别时下载到仓库的 `content/homework/`（不进 git）。“设备与数据”页可以按孩子导出或删除全部数据。

## 断网

- 课程开始后断网，孩子可以继续学完；学习记录先存在 iPad 上，网络恢复后自动补传，不会重复。
- 想让 iPad 在断网时也能重新打开已经开过的课，需要用 HTTPS 访问（浏览器只在 HTTPS 下启用离线缓存）。家里可以用 Tailscale 的 `tailscale serve`，云主机用 Caddy 自动证书。

## 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `ADW_PIN` | 必填 | 家长 PIN，4–12 位数字 |
| `PORT` | 8787 | 端口 |
| `ADW_DB` | `data/adw.sqlite` | 数据文件；备份时连同旁边的 `homework/` 目录一起复制 |
| `ADW_TENANT` | `family-001` | 家庭编号 |

日期一律按北京时间由服务器判断，iPad 改系统时间不会多出课。
