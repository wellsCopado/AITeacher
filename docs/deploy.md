# 部署家里的服务器

服务器一个进程同时提供：内容接口（`/v1/…`）、孩子用的 Pad 轻 App（`/pad/`）、家长端网页（`/parent/`）。数据存在一个 SQLite 文件里。

## 放在哪里

| 方式 | 适合 | 说明 |
| --- | --- | --- |
| 家里一直开着的电脑或 NAS | 先家用 | 数据不出家门；Pad 和服务器在同一个 Wi-Fi 下 |
| 一台小云主机 | 在外面也想用、以后商用 | 需要域名和 HTTPS；每行数据已带 `tenant_id`，以后可以分家庭 |

## 方式一：Docker（推荐）

```
docker build -t adw .
docker run -d --name adw -p 8787:8787 \
  -e ADW_PIN=你的家长PIN \
  -v adw-data:/app/data --restart unless-stopped adw
```

## 方式二：直接用 Node（需要 Node 22.5 以上）

```
pnpm install
ADW_PIN=你的家长PIN pnpm start
```

## 第一次使用

1. 电脑上打开 `http://<服务器地址>:8787/parent/`，输入 PIN。
2. 孩子的 iPad 用 Safari 打开 `http://<服务器地址>:8787/pad/`，屏幕上会出现 6 位配对码。
3. 家长端“设备”页输入配对码、起个名字（比如“哥哥的 iPad”），点批准。iPad 几秒内自动连上。
4. iPad 上点分享 → “添加到主屏幕”，以后像 App 一样打开。

## 审核、发布和排课

课程在本仓库里用 Skill 做好后，用 `dls submit … --server` 交给服务器（服务器第一次启动时，`content/lessons/` 里已经组装好的课也会自动放进来）。之后都在家长端完成：

1. 「课程库」→“等你审核”：点“预览这节课”走一遍，逐项勾选四类审核，点“审核通过并发布”。要改就写一句意见点“退回修改”。
2. 「排课」：勾选日期，孩子当天就能看到；想让孩子提前或补做，用「课程库」里的临时授权（1–7 天）。
3. 「课程库」→“生物素材”：还没有写实模型的动物（比如孔雀螳螂虾），在这里加实拍照片或视频（iPhone 拍的 mov 也行，48 MB 以内）。要写作者和授权，并勾选“这是实拍或扫描，不是卡通”。孩子在课里点洞口就会打开实拍观察窗。可以从维基共享资源（commons.wikimedia.org）找 CC 授权的照片，把作者和授权照抄过来。

### 孩子上课时

- 每一步都有引导和倒计时：说明会自动出字幕并朗读，听完才能开始演示；演示里一件一件做，没做的到时间会自动帮他做；题目一题一题出；每一步到时间自动进下一步，最后一步到时间就结束。孩子不能点上面的步骤跳着走（家长预览可以）。
- 每次检查答案都会先具体地夸孩子做对的地方（比如“周长完全做对了”“数算对了，只差单位”），再说要看哪里，再给一个坚持下去的理由。同一道题错 3 次，Pad 会说“我们一起看一遍怎么做”，一步一步演示（字幕加朗读），然后出一道同类题让孩子自己做一次，做完进下一题，不会卡住。学习记录里能看到哪道题看了演示、同类题有没有自己做对。
- 3D 场景里的螳螂虾是用四张写实图做成的可动立体模型：点「看看螳螂虾的洞」它会从洞里爬出来、四处走，下面一排按钮可以看它出拳、40 倍慢动作出拳、拆开看身体各部分的名字、看照片、让它退回洞里。
- 讲解固定 1 中 3 英：同一个讲解第 1 次中文，第 2 到 4 次英文。朗读用服务器那台 Mac 的语音生成，发到 Pad 当普通音频播放，静音开关开着也能听到。服务器自动挑最像真人的声音（“高级 Premium”优先，其次“增强 Enhanced”），用声音本来的语速。家长端「设备与数据 → 朗读声音」可以试听、更换，也可以选“Mac 系统朗读声音”（在 Mac 设置里把系统声音设成 Siri 声音时最自然）；也可以用环境变量 `ADW_VOICE_ZH`、`ADW_VOICE_EN` 指定。想要更像真人：Mac 上打开 系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音，下载中文 Lilian（高级）或婷婷（增强）、英文 Ava（高级）或 Zoe（高级），重启服务。不是 Mac 或没有中文语音时，Pad 改用 iPad 自带语音。每节课先点“开始上课”，这一下同时打开声音。Pad 首页有“🔊 声音测试”，会显示用的是哪个语音、是不是桌面 App 模式和版本号。

### 把 Pad 装成桌面 App

在 iPad 的 Safari 里打开 `http://<服务器地址>:8787/pad/`，点地址栏旁的分享按钮，选“添加到主屏幕”。以后从桌面的“探索世界”图标打开：全屏、没有地址栏和标签页，横屏使用。不需要 App Store。还在 Safari 里打开时，点任何按钮都会自动进入全屏，右上角 ⛶ 可以切换。

服务器会再跑一遍 V01–V18，不过的课不能发布。孩子在课末说的“下一课想学什么”会自动记进「兴趣与心愿」；做下一节课前运行 `dls sync --server …` 同步回来。

## 更新到新版本

在跑服务器的终端里按 `Ctrl + C` 停掉，然后：

```
cd ~/AITeacher && git pull && npx -y pnpm@10.28.0 install
ADW_PIN=你的家长PIN npx -y pnpm@10.28.0 start
```

数据在 `data/` 里，更新不会丢。

## 作业判断

1. 家长端“作业”页上传照片（一次最多 8 张，浏览器里先压缩）。想让 Claude 识别就勾选“同意用 Claude 识别”。
2. 在本仓库里用 Claude Code 说“看看今天的作业”。Skill 会下载照片、逐题识别并上传。
3. 家长在“作业”页逐题核对（标“请核对”的题必须单独看），识别错了直接改。
4. Skill 写判断；家长看过后点“确认”。“需再支持”的知识点会生成重教需求，在“掌握与重教”页能看到。
5. 说“按重教需求做一节课”，Skill 会换一种教法重做；下一次作业再判断，独立做对了重教需求自动标“已验证”。

作业照片存在数据目录的 `homework/` 下（默认 `data/homework/`），不进数据库，也不出这台机器；Skill 识别时下载到仓库的 `content/homework/`（不进 git）。“设备与数据”页可以按孩子导出或删除全部数据。

## 断网

- 课程开始后断网，孩子可以继续学完；学习记录先存在 iPad 上，网络恢复后自动补传，不会重复。
- 想让 iPad 在断网时也能重新打开已经开过的课，需要用 HTTPS 访问（浏览器只在 HTTPS 下启用离线缓存）。家里可以用 Tailscale 的 `tailscale serve`，云主机用 Caddy 自动证书。

## 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `ADW_PIN` | 必填 | 家长 PIN，4–12 位数字 |
| `PORT` | 8787 | 端口 |
| `ADW_DB` | `data/adw.sqlite` | 数据文件；备份时连同旁边的 `homework/` 目录一起复制 |
| `ADW_TENANT` | `family-001` | 家庭编号 |

日期一律按北京时间由服务器判断，iPad 改系统时间不会多出课。
